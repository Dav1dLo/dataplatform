## Functional process 
This table supports the inventory scrap management process by providing a categorization system for stock scrap events. It allows warehouse operators to tag scrap records with specific reasons (e.g., "Damaged", "Expired", "Obsolete"), facilitating granular reporting on inventory loss and shrinkage.

## Description
One row represents a single scrap reason tag definition available for selection within the Odoo inventory module. This is a raw landed copy of the Odoo configuration entity, serving as a reference table for downstream inventory analysis and scrap reporting.
