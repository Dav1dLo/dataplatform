# odoo_website

## Source system
This table originates from Odoo ERP, specifically the website module. The naming convention (e.g., `company_id`, `write_uid`, `create_date`) and the presence of specific Odoo-related fields like `configurator_done` and `auth_signup_uninvited` are characteristic of the Odoo `website` model.

## Functional process 
This table supports the multi-website management process within Odoo. It acts as the central configuration registry for each website instance hosted on the platform, managing site-specific settings, social media integrations, third-party analytics keys, and custom code injections.

## Description
One row in this table represents a single website instance configured within the Odoo environment. It serves as a raw landed copy of the Odoo `website` table, capturing the operational configuration and metadata for each site at the grain of one row per website.

## Caveats for downstream consumers

- **Sensitive Data:** Contains API keys (`google_analytics_key`, `google_maps_api_key`, `plausible_shared_key`) which should be masked in reporting environments.
- **Timestamps:** `create_date` and `write_date` are stored in UTC.
- **Soft Deletes:** Odoo typically uses hard deletes for configuration tables; assume no soft-delete flag exists unless `active` column is present (not present here).
- **Custom Code:** The `custom_code_head` and `custom_code_footer` fields contain raw HTML/JS and should be treated as untrusted input if rendered in a browser.
