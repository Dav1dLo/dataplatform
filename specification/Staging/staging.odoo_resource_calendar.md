# odoo_resource_calendar

## Source system
This table originates from Odoo ERP, as evidenced by the characteristic naming convention of Odoo's resource management module (`resource_calendar`), the presence of audit fields like `create_uid` and `write_uid`, and the use of Odoo-specific sequence generators for the primary key.

## Functional process 
This table supports the Human Resources and Project Management modules by defining working time schedules. It dictates the operational hours, time zones, and flexibility settings for employees or resources, which are subsequently used to calculate availability, capacity planning, and leave accruals.

## Description
One row in this table represents a single working time definition or calendar profile used within the organization. It serves as a raw landed copy of the Odoo `resource.calendar` model, capturing the configuration for standard, flexible, or bi-weekly working schedules.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| company_id | INTEGER | true | Foreign key to the company | Links the calendar to a specific legal entity. |
| create_uid | INTEGER | true | Creator user ID | ID of the user who created the record. |
| write_uid | INTEGER | true | Last modifier user ID | ID of the user who last updated the record. |
| name | VARCHAR | false | Calendar name | Descriptive label for the schedule (e.g., "Standard 40h/week"). |
| tz | VARCHAR | false | Timezone | IANA timezone string (e.g., "UTC", "Europe/Brussels"). |
| hours_per_day | NUMERIC | true | Daily hours | Average or standard hours worked per day. |
| active | BOOLEAN | true | Soft-delete flag | If false, the calendar is archived/inactive. |
| two_weeks_calendar | BOOLEAN | true | Bi-weekly flag | Indicates if the schedule follows a 2-week rotation. |
| flexible_hours | BOOLEAN | true | Flexibility flag | Indicates if the resource has flexible working hours. |
| create_date | TIMESTAMP | true | Creation timestamp | Record creation time in UTC. |
| write_date | TIMESTAMP | true | Last update timestamp | Last modification time in UTC. |
| full_time_required_hours | DOUBLE PRECISION | true | Full-time threshold | The number of hours required to be considered full-time. |

## Caveats for downstream consumers

- **Soft Deletes:** The `active` column is used for soft deletes; ensure queries filter by `active = TRUE` unless historical data is explicitly required.
- **Timezones:** The `tz` column contains IANA timezone identifiers; ensure downstream transformations account for these when calculating start/end times for shifts.
- **Audit Timestamps:** `create_date` and `write_date` are stored in UTC as per Odoo standard behavior.
- **Precision:** `hours_per_day` is a `NUMERIC` type; be aware of potential rounding if performing arithmetic in downstream SQL.
