# odoo_mrp_unbuild

## Source system
This table originates from Odoo ERP, specifically the Manufacturing (MRP) module. The naming convention `mrp_unbuild` and the presence of foreign keys like `bom_id` (Bill of Materials) and `mo_id` (Manufacturing Order) are characteristic of the Odoo database schema.

## Functional process 
This table supports the manufacturing unbuild process, where finished products are disassembled back into their component parts. It tracks the reversal of production orders, allowing the system to return components to inventory and update stock levels based on the disassembly of a specific quantity of a product.

## Description
One row in this table represents a single unbuild order, documenting the disassembly of a specific quantity of a product. It serves as a raw landed copy of the Odoo `mrp.unbuild` model, capturing the state of the unbuild process, the associated manufacturing order, and the source/destination inventory locations.

## Caveats for downstream consumers

- **Timestamps:** Timestamps are stored in UTC as per Odoo standard behavior.
- **Soft Deletes:** Odoo typically performs hard deletes on records; however, verify if the source system has been configured for archival.
- **Data Integrity:** `bom_id` and `mo_id` are nullable, meaning some unbuilds may be performed ad-hoc without a direct link to a production order or a predefined BoM.
- **Precision:** `product_qty` is `NUMERIC`; ensure downstream systems handle the scale and precision defined in the Odoo source configuration.
