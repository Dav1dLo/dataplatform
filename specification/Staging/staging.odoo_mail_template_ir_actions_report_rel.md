# odoo_mail_template_ir_actions_report_rel

## Source system
This table originates from Odoo ERP. The naming convention `_rel` combined with the specific module prefixes `mail_template` and `ir_actions_report` is characteristic of Odoo's internal many-to-many relationship tables, which are automatically generated by the Odoo ORM to link email templates to report actions.

## Functional process 
This table supports the document automation and reporting process within Odoo. It manages the many-to-many relationship between email templates (used for automated notifications) and report actions (which define the PDF or document generation logic), allowing a single email template to be associated with multiple report outputs or vice versa.

## Description
One row in this table represents a single association between an email template and a report action. It serves as a raw landing copy of the Odoo join table, facilitating the reconstruction of relationships between communication templates and generated business documents in the staging layer.
