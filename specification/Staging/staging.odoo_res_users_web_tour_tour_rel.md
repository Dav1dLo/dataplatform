# odoo_res_users_web_tour_tour_rel

## Source system
This table originates from Odoo ERP. The naming convention `res_users_web_tour_tour_rel` is characteristic of Odoo's internal many-to-many relationship tables, which are automatically generated by the Odoo ORM to link user records with web tour progress or configuration records.

## Functional process 
This table supports the user onboarding and guided tour tracking process within the Odoo platform. It maps specific users to the web tours they have interacted with or completed, facilitating the "User-to-Tour" association required to prevent redundant tour prompts or to track feature adoption.

## Description
One row in this table represents a single association between a user and a specific web tour. It is a raw landing of a join table, serving as the bridge between user accounts and tour definitions. It exists in the staging layer to allow for the reconstruction of user-level tour progress in downstream analytical models.
