# odoo_account_tax_group

## Source system
This table originates from Odoo ERP, specifically the accounting module. The naming convention (e.g., `company_id`, `create_uid`, `write_date`) and the use of `JSONB` for localized fields are characteristic of Odoo's PostgreSQL-based data architecture.

## Functional process 
This table supports the tax configuration and reporting process within the financial accounting module. It defines groupings for tax rates, which are used to aggregate tax amounts on invoices and point-of-sale receipts, and maps these groups to specific general ledger accounts for payables, receivables, and advance payments.

## Description
One row in this table represents a single tax group definition used to categorize taxes for reporting and accounting purposes. It acts as a raw landed copy of the Odoo `account.tax.group` model, capturing the configuration of how taxes are grouped and their associated ledger accounts.

- **Timestamps:** Timestamps are stored in UTC as per standard Odoo behavior.
