# odoo_account_report_external_value

## Source system
This table originates from Odoo ERP, specifically the accounting and financial reporting module. The naming convention (`account_report_external_value`) and the presence of columns like `company_id`, `create_uid`, and `fiscal_position_id` are characteristic of Odoo's internal ORM structure for managing financial report data.

## Functional process 
This table supports the financial reporting and tax compliance process, specifically for handling external values or carryover amounts in accounting reports. It tracks manual adjustments or external data points that need to be included in financial statements, often related to cross-border VAT or carryover balances between reporting periods.

## Description
One row in this table represents a single external value entry or adjustment associated with a specific financial report expression. It serves as a raw landed copy of the Odoo `account.report.external.value` model, capturing the state of manual report overrides or carryover data at the time of ingestion.
