# odoo_mail_alias

## Source system
This table originates from Odoo ERP, specifically the `mail` module. The naming convention (e.g., `alias_model_id`, `alias_defaults`, `create_uid`) and the presence of `JSONB` and `TIMESTAMP` fields are characteristic of the Odoo PostgreSQL schema structure.

## Functional process 
This table supports the Odoo email routing and automation process. It defines how incoming emails are mapped to specific business objects (models) within the system, such as creating tasks from emails, updating support tickets, or routing messages to specific document threads.

## Description
One row in this table represents a single email alias configuration used to route incoming messages to Odoo records. It acts as a raw landing copy of the Odoo `mail.alias` model, capturing the routing logic, default values for created records, and the target model association.

## Caveats for downstream consumers

- **Sensitive Data:** `alias_bounced_content` may contain PII from original email headers or body content.
- **Timestamps:** All `TIMESTAMP` fields are stored in UTC by Odoo.
- **Data Format:** `alias_defaults` is stored as a `TEXT` field but contains a JSON-encoded string; it will require parsing (e.g., `jsonb_to_record` or `::jsonb`) for analysis.
- **Soft Deletes:** Odoo typically does not use soft deletes in this table; records are usually physically removed.
