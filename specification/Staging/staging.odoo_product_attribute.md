# odoo_product_attribute

## Source system
This table originates from Odoo ERP, as evidenced by the characteristic naming conventions such as `create_uid`, `write_uid`, `create_date`, and the use of `JSONB` for multi-language fields (a standard pattern in Odoo's PostgreSQL backend).

## Functional process 
This table supports the Product Catalog management process, specifically defining the attributes (e.g., "Color", "Size", "Material") that can be assigned to product variants. It governs how these attributes are displayed in the user interface and whether they are used to generate unique product variants.

## Description
One row represents a single product attribute definition within the Odoo system. This is a raw landing table in the staging layer, containing the configuration settings for attributes used to categorize or differentiate products.
