# odoo_resource_resource

## Source system
This table originates from Odoo ERP, specifically the `resource.resource` model. The naming convention, presence of `create_uid`/`write_uid` audit columns, and the `resource_type` field are characteristic of Odoo's internal resource management framework used for tracking employees, vehicles, or equipment.

## Functional process 
This table supports the Resource Management process, which defines the availability and capacity of entities (human or material) within the organization. It is used to link users to specific working calendars and define their time efficiency, which is critical for project scheduling, manufacturing capacity planning, and attendance tracking.

## Description
One row in this table represents a single resource entity, such as an employee or a piece of equipment, defined within the Odoo system. This is a raw landing of the Odoo `resource.resource` table, serving as the base staging entity for downstream workforce and capacity analytics.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| company_id | INTEGER | true | Foreign key to the company | Links the resource to a specific organizational unit. |
| user_id | INTEGER | true | Foreign key to the user | Links the resource to a system user account. |
| calendar_id | INTEGER | true | Foreign key to the working calendar | Defines the working hours/shifts for this resource. |
| create_uid | INTEGER | true | ID of the user who created the record | Audit field for record creation. |
| write_uid | INTEGER | true | ID of the user who last updated the record | Audit field for record modification. |
| name | VARCHAR | false | Display name of the resource | The human-readable identifier. |
| resource_type | VARCHAR | false | Type of resource | e.g., 'user' or 'material'. |
| tz | VARCHAR | false | Timezone string | IANA timezone identifier for the resource. |
| active | BOOLEAN | true | Soft-delete flag | If false, the resource is archived. |
| create_date | TIMESTAMP | true | Creation timestamp | UTC timestamp of record creation. |
| write_date | TIMESTAMP | true | Last update timestamp | UTC timestamp of last modification. |
| time_efficiency | DOUBLE PRECISION | false | Efficiency factor | Multiplier for capacity (e.g., 1.0 = 100%). |

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `company_id` → `res_company.id` (Standard Odoo multi-company architecture).
    - `user_id` → `res_users.id` (Standard Odoo user association).
    - `calendar_id` → `resource_calendar.id` (Standard Odoo scheduling association).
- **Natural keys (inferred):** Not confidently inferable; Odoo typically relies on the surrogate `id` for internal references.

## Caveats for downstream consumers

- **Sensitive Data:** The `user_id` and `name` fields may be considered PII depending on organizational policy.
- **Timestamps:** Timestamps are stored in UTC as per standard Odoo behavior.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = TRUE` unless historical analysis of archived resources is required.
- **Precision:** `time_efficiency` is a float; ensure downstream calculations handle potential floating-point rounding issues.
