# odoo_product_category

## Source system
This table originates from Odoo ERP, as evidenced by the characteristic naming conventions such as `create_uid`, `write_uid`, `parent_path`, and the extensive use of `JSONB` fields for property-based accounting and valuation configurations typical of the Odoo framework.

## Functional process 
This table supports the product catalog management and inventory accounting configuration process. It defines the hierarchical structure of product categories and stores the default accounting and valuation rules (e.g., income/expense accounts, cost methods) that are inherited by products assigned to these categories.

## Description
One row in this table represents a single product category within the Odoo product hierarchy. It serves as a raw landed copy of the Odoo `product.category` model, capturing both the organizational structure (via `parent_id` and `parent_path`) and the associated business logic for inventory and financial accounting.

## Caveats for downstream consumers

- **JSONB Fields:** Many columns are `JSONB` types. These often contain Odoo "property" references (e.g., `{"value": 123}`). You will likely need to extract the integer value using `(property_valuation->>'value')::int` for joins.
- **Timestamps:** Timestamps are stored in UTC as per Odoo standard behavior.
- **Soft Deletes:** This table does not implement a visible `active` flag; assume all rows are current unless an `active` column is added by the ingestion process.
- **Hierarchy:** Use the `parent_path` column for recursive tree queries rather than self-joining on `parent_id` for better performance.
