# odoo_hr_employee

## Source system
This table originates from Odoo ERP, specifically the Human Resources module. The naming convention (e.g., `resource_id`, `create_uid`, `write_date`) and the specific structure of HR-related fields (e.g., `identification_id`, `visa_no`, `work_permit_expiration_date`) are characteristic of the Odoo `hr.employee` model.

## Functional process 
This table supports the core Human Resources management process, including employee lifecycle management, organizational structure mapping, and personal data administration. It tracks employee assignments to departments and jobs, manages contact information, and maintains sensitive regulatory data such as work permits, identification numbers, and emergency contact details.

## Description
One row in this table represents a single employee record within the Odoo system. It captures both professional attributes (job title, department, work contact) and personal details (private address, birthdate, marital status). This is a raw landed staging table, serving as the primary source for downstream HR reporting and organizational analytics.

## Caveats for downstream consumers

- **Sensitive Data:** This table contains significant PII (SSN, home address, private phone, spouse details). Ensure strict access control and masking for non-HR users.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless performing historical analysis.
- **Timestamps:** `create_date` and `write_date` are stored in UTC as per standard Odoo behavior.
- **Data Quality:** Many fields are nullable; expect missing data for non-mandatory HR fields.
