# odoo_hr_resume_line

## Source system
This table originates from Odoo ERP, specifically the Human Resources module. The naming convention `hr_resume_line` and the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's internal ORM structure.

## Functional process 
This table supports the employee profile management process, specifically tracking historical resume entries such as work experience, education, or certifications. It links individual employees to specific career milestones or qualifications via the `employee_id` and `line_type_id` references.

## Description
One row in this table represents a single resume line item (e.g., a specific job title or degree) associated with an employee. This is a raw landing table in the staging layer, capturing the state of resume entries as they exist in the Odoo database.
