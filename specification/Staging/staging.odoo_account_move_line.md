# odoo_account_move_line

## Source system
This table originates from Odoo ERP, specifically the accounting module. The naming convention `account_move_line` and the presence of columns like `journal_id`, `reconcile_model_id`, and `tax_line_id` are characteristic of Odoo's double-entry bookkeeping architecture.

## Functional process 
This table supports the core financial accounting and general ledger process. It records the individual line items (debits and credits) that constitute a financial transaction (`move_id`), facilitating trial balance generation, tax reporting, and accounts receivable/payable tracking.

## Description
One row in this table represents a single entry in a journal item, representing a debit or credit against a specific general ledger account. As a staging table, it provides a raw, landed copy of the Odoo `account.move.line` model, capturing the granular financial details of every transaction posted in the system.

    - `account_id` → `account_account.id` (Links to the general ledger account)

## Caveats for downstream consumers

- **Sensitive Data:** Contains `partner_id` and potentially PII in the `name` or `ref` fields; ensure appropriate masking for non-finance users.
- **Timestamps:** `create_date` and `write_date` are assumed to be in UTC.
- **Soft Deletes:** Odoo typically does not use soft deletes in this table; records are usually permanent once posted.
- **Precision:** `NUMERIC` types in Odoo are typically high-precision; ensure downstream systems accommodate the scale (usually 2-4 decimal places).
- **Balance Logic:** Always use the `balance` column for ledger reporting rather than calculating `debit - credit` manually to ensure consistency with Odoo's internal logic.
