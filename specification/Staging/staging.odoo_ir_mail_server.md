# odoo_ir_mail_server

## Source system
This table originates from Odoo ERP, specifically the `ir_mail_server` model within the Odoo framework. The naming convention (e.g., `ir_` prefix for internal records) and the presence of specific columns like `google_gmail_refresh_token` and `smtp_host` are characteristic of Odoo's outgoing mail server configuration management.

## Functional process 
This table supports the system's email infrastructure configuration, managing the connection details for outgoing SMTP servers used by the ERP to send transactional emails (invoices, notifications, etc.). It facilitates the integration between the ERP and external mail providers, including standard SMTP services and Google Gmail API-based authentication.

## Description
One row in this table represents a single configured outgoing mail server instance within the Odoo environment. It stores connection parameters, authentication credentials, and security settings required for the application to route outbound mail. This is a raw landed copy of the Odoo configuration table, intended for auditing or monitoring mail server connectivity.

## Caveats for downstream consumers

- **Sensitive Data:** This table contains highly sensitive information, including `smtp_pass`, `smtp_ssl_private_key`, `google_gmail_refresh_token`, and `google_gmail_access_token`. These columns must be masked or excluded from non-privileged reporting environments.
- **Timestamps:** `create_date` and `write_date` are assumed to be in UTC, consistent with standard Odoo database practices.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should filter by `WHERE active = TRUE` to retrieve only currently enabled mail servers.
- **Binary Data:** `smtp_ssl_certificate` and `smtp_ssl_private_key` are stored as `BYTEA` (binary); these are generally not useful for standard SQL analysis and should be ignored unless performing security audits.
