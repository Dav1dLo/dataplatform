# odoo_stock_package_type

## Source system
This table originates from Odoo ERP, specifically the Inventory/Warehouse module. The naming convention `stock_package_type` and the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's ORM-generated database schema.

## Functional process 
This table supports the warehouse management and logistics process by defining the physical specifications of packaging containers (e.g., boxes, pallets, or crates). These definitions are used during the picking and packing workflow to calculate shipping volumes, weight limits, and to generate barcodes for package identification.

## Description
One row represents a single type of packaging container defined within the Odoo inventory system. It captures the physical dimensions, weight constraints, and identification details for a specific package category. As a staging table, it serves as a raw, direct copy of the Odoo `stock.package.type` model, intended for downstream transformation into inventory dimensions.

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may need to be mapped to anonymized user names if exposed to non-admin reporting.
- **Timestamps:** Odoo stores timestamps in UTC; ensure downstream transformations account for this if local time reporting is required.
- **Soft Deletes:** Odoo typically does not use soft-delete flags; records are usually physically deleted from the source.
- **Units of Measure:** The `DOUBLE PRECISION` columns (height, width, length, weight) do not have units explicitly defined in this table. These are governed by the global Odoo UoM settings; verify the unit configuration in the source system before performing calculations.
