# odoo_account_report

## Source system
This table originates from Odoo ERP, specifically the accounting and financial reporting module. The naming convention (`account_report`, `chart_template`, `filter_journals`) and the presence of Odoo-specific patterns like `create_uid`, `write_uid`, and `JSONB` name fields are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the financial reporting configuration process. It defines the structure, UI filters, and behavioral settings for various financial reports (e.g., Balance Sheet, P&L) available within the Odoo accounting interface. It dictates which filters (like date ranges, journals, or analytic accounts) are exposed to users when generating specific financial statements.

## Description
One row in this table represents a single financial report configuration definition. It acts as a raw landed copy of the Odoo `account.report` model, capturing the metadata and UI toggle settings that govern how a report is rendered and filtered in the application.

## Caveats for downstream consumers

- **Localization:** The `name` column is `JSONB`; ensure you extract the correct language key (e.g., `name->>'en_US'`) when joining or reporting.
- **Timestamps:** `create_date` and `write_date` are assumed to be in UTC, consistent with standard Odoo database configurations.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless auditing archived reports.
- **Data Pattern:** This is a raw staging table; expect Odoo-specific internal identifiers that may not be human-readable without joining to corresponding `res_` or `account_` tables.
