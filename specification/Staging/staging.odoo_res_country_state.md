# odoo_res_country_state

## Source system
This table originates from Odoo ERP, a modular business management software. The naming convention `res_country_state` is standard for Odoo's "Resources" module, which manages core master data entities like countries, states, and partners.

## Functional process 
This table supports the geographical master data management process. It maintains the registry of administrative subdivisions (states, provinces, or regions) linked to countries, which is essential for address validation, tax calculation, and shipping logistics across the Odoo ecosystem.

## Description
One row in this table represents a single administrative state or province within a country. This is a raw landed copy of the Odoo `res_country_state` table, serving as the staging entity for downstream geographical dimension tables.

## Caveats for downstream consumers

- **Timestamps:** Timestamps are assumed to be in UTC, consistent with Odoo's internal storage format.
- **Data Integrity:** As a staging table, this contains raw Odoo data; ensure joins to `res_users` or `res_country` account for potential missing records if the full Odoo schema is not present.
- **Soft Deletes:** Odoo typically does not use soft-delete flags in this table; records are usually physically deleted from the source.
- **Precision:** The `VARCHAR` columns do not have explicit length constraints defined in the metadata; verify against source DDL if strict length validation is required for downstream loading.
