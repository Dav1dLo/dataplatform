# odoo_purchase_order

## Source system
This table originates from Odoo ERP, specifically the Purchase module. The naming conventions (e.g., `partner_id`, `picking_type_id`, `incoterm_id`) and the presence of Odoo-specific audit fields like `create_uid` and `write_uid` are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the Procure-to-Pay (P2P) business process. It tracks the lifecycle of purchase orders from creation and approval through to receipt status and invoicing, facilitating inventory replenishment and vendor management.

## Description
One row represents a single purchase order header record within the Odoo system. This table serves as the raw landed staging entity, capturing the state, financial totals, and key timestamps for each procurement request.

## Caveats for downstream consumers

- **Sensitive Data:** Contains `partner_id` and potentially PII in `notes` or `partner_ref`.
- **Timestamps:** Assumed to be in UTC as per standard Odoo configuration.
- **Soft Deletes:** Odoo typically uses hard deletes for records, but check for `active` flags if available in other tables.
- **Precision:** `NUMERIC` types are used for financial values; ensure downstream systems handle rounding consistently with Odoo's internal logic.
