# odoo_ir_filters

## Source system
This table originates from Odoo ERP, specifically the `ir_filters` model within the framework's internal registry (the "ir" prefix stands for "internal registry"). It captures user-defined search filters and saved views across the platform.

## Functional process 
This table supports the UI personalization and saved search functionality within the Odoo application. It allows users to save specific search criteria (`domain`) and view configurations (`context`) for various business models, enabling quick access to filtered data sets across the CRM, Sales, and Inventory modules.

## Description
One row represents a single saved filter or search configuration created by a user for a specific Odoo model. This is a raw landing of the Odoo `ir_filters` table, serving as the staging layer for downstream reporting on user activity and saved view preferences.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| user_id | INTEGER | true | Owner of the filter | Foreign key to the Odoo user table. |
| action_id | INTEGER | true | Associated action | Links the filter to a specific window action. |
| embedded_action_id | INTEGER | true | Embedded action ID | Used for filters within embedded views. |
| embedded_parent_res_id | INTEGER | true | Parent resource ID | Contextual link for embedded resources. |
| create_uid | INTEGER | true | Creator user ID | Audit trail for who created the filter. |
| write_uid | INTEGER | true | Last modifier user ID | Audit trail for who last updated the filter. |
| name | VARCHAR | false | Filter display name | The label shown to the user in the UI. |
| sort | VARCHAR | false | Sort order | Defines the default sorting for the view. |
| model_id | VARCHAR | false | Target model identifier | The Odoo model (e.g., 'sale.order') the filter applies to. |
| domain | TEXT | false | Filter criteria | The Odoo domain expression (JSON-like list). |
| context | TEXT | false | View context | Additional parameters for the view state. |
| is_default | BOOLEAN | true | Default flag | If true, this is the default filter for the user. |
| active | BOOLEAN | true | Soft-delete flag | Indicates if the filter is currently enabled. |
| create_date | TIMESTAMP | true | Creation timestamp | UTC timestamp of record creation. |
| write_date | TIMESTAMP | true | Last update timestamp | UTC timestamp of last modification. |

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `user_id` → `res_users.id` (Standard Odoo pattern for user ownership).
    - `create_uid` → `res_users.id` (Standard Odoo audit trail).
    - `write_uid` → `res_users.id` (Standard Odoo audit trail).
- **Natural keys (inferred):** Not confidently inferable; Odoo filters are typically identified by the combination of `user_id`, `model_id`, and `name`.

## Caveats for downstream consumers

- **Sensitive Data:** Contains `domain` and `context` fields which may expose internal business logic or specific search parameters that could be considered sensitive.
- **Timestamps:** Timestamps are stored in UTC as per Odoo standard behavior.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = TRUE` unless historical analysis is required.
- **Data Format:** The `domain` and `context` columns contain serialized Python/Odoo expressions; these will require parsing (e.g., `ast.literal_eval` in Python or regex in SQL) to be useful for filtering.
