# odoo_project_share_wizard_res_partner_rel

## Source system
This table originates from Odoo ERP. The naming convention `_rel` combined with the specific module-related entities `project_share_wizard` and `res_partner` is characteristic of Odoo's many-to-many relationship tables, which are automatically generated by the ORM to link wizard instances to partner records.

## Functional process 
This table supports the project sharing functionality within Odoo, specifically tracking which partners (contacts/users) are associated with a specific project share wizard session. It facilitates the process of granting access or sharing project-related information with external or internal stakeholders.

## Description
One row in this table represents a single association between a project share wizard instance and a partner record. It serves as a raw landing join table in the staging layer, maintaining the many-to-many relationship required to manage project access permissions during the sharing workflow.
