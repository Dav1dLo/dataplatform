# odoo_account_account_tag

## Source system
This table originates from Odoo ERP, specifically the accounting module. The naming convention `odoo_account_account_tag` and the presence of Odoo-specific audit columns like `create_uid`, `write_uid`, and `JSONB` fields for multi-language names are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the financial reporting and tax configuration process. It manages tags used to categorize accounts for specific reporting requirements, such as tax report lines or balance sheet groupings, allowing for flexible financial analysis beyond the standard chart of accounts.

## Description
One row represents a single account tag definition used to label or group financial accounts. This is a raw landed copy of the Odoo `account.account.tag` model, serving as a staging entity for downstream financial reporting dimensions.
