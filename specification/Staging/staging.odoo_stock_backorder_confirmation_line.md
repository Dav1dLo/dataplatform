## Functional process 
This table supports the inventory fulfillment process, specifically the management of backorders. It records the confirmation state of individual picking lines when a partial delivery or receipt occurs, determining whether the remaining items should be split into a new backorder or cancelled.

## Description
One row in this table represents a single line item within a backorder confirmation wizard, linking a specific picking operation to a confirmation event. It serves as a raw landed copy of the Odoo `stock.backorder.confirmation.line` model, capturing the user's decision to create a backorder for a specific stock movement.
