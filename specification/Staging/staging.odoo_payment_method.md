# odoo_payment_method

## Source system
This table originates from Odoo ERP, as evidenced by the characteristic naming conventions such as `create_uid`, `write_uid`, `create_date`, and `write_date`, which are standard audit columns in the Odoo ORM. The use of `JSONB` for the `name` column is also consistent with Odoo's multi-language field storage pattern.

## Functional process 
This table supports the payment processing and checkout configuration module. It defines the available payment methods (e.g., credit card, wire transfer, PayPal) and their functional capabilities, such as whether they support tokenization, express checkout, or refunds, which are critical for the e-commerce and invoicing checkout workflows.

## Description
One row in this table represents a single payment method configuration available within the Odoo environment. This is a raw landed copy of the Odoo `payment.method` model, serving as the staging entity for downstream payment dimension tables. It captures both the identity of the payment method and its functional feature flags.

## Caveats for downstream consumers

- **Sensitive Data:** No direct PII or payment credentials (like PANs) are stored here; this table contains configuration metadata only.
- **Timestamps:** Odoo typically stores timestamps in UTC; however, ensure verification against the application server configuration.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless performing historical audits.
- **JSONB:** The `name` column is a `JSONB` object containing translations. Downstream consumers will need to extract the relevant language key (e.g., `name->>'en_US'`).
