# odoo_stock_location

## Source system
This table originates from Odoo ERP, specifically the Inventory/Warehouse management module. The naming conventions (`posx`, `posy`, `posz`, `removal_strategy_id`, `parent_path`) are characteristic of Odoo's hierarchical stock location model.

## Functional process 
This table supports the warehouse management and inventory control process. It defines the physical or logical structure of the warehouse (e.g., shelves, bins, transit locations, or scrap areas) and governs inventory movement logic, such as removal strategies and replenishment settings.

## Description
One row represents a single stock location within the Odoo warehouse hierarchy. This is a raw landed copy of the Odoo `stock.location` model, capturing both physical coordinates and operational configuration for inventory tracking.

## Caveats for downstream consumers

- **Sensitive Data:** No direct PII, but contains internal warehouse configuration and accounting account references.
- **Timestamps:** Assumed to be in UTC, consistent with Odoo's standard database storage.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; queries should generally filter by `WHERE active = TRUE` unless performing historical audits.
- **Hierarchy:** The `parent_path` column is a materialized path string (e.g., "1/5/12"); use this for efficient recursive queries rather than self-joining on `location_id` where possible.
- **Data Types:** `VARCHAR` fields do not have explicit lengths defined in the source metadata; assume standard Odoo lengths (usually 255) but verify if truncating during ETL.
