# odoo_crm_tag

## Source system
This table originates from Odoo ERP, specifically the CRM module. The naming convention (`crm_tag`), the presence of `create_uid`/`write_uid` audit columns, and the use of `JSONB` for the `name` field are characteristic of Odoo's PostgreSQL-based ORM architecture.

## Functional process 
This table supports the CRM lead and opportunity management process by providing a taxonomy for categorizing records. Tags are used to label leads or opportunities with descriptive attributes (e.g., "High Priority", "Webinar Attendee"), allowing for better segmentation and reporting within the sales pipeline.

## Description
One row represents a single CRM tag definition available for assignment to leads or opportunities. It acts as a raw landed copy of the Odoo `crm.tag` model, capturing the tag's display properties and audit metadata. The grain is one row per unique tag ID.

## Caveats for downstream consumers

- **JSONB Handling:** The `name` column is stored as `JSONB`. To extract the tag name, use `name->>'en_US'` or the appropriate language key used in your Odoo instance.
- **Timestamps:** All timestamps (`create_date`, `write_date`) are stored in UTC.
- **Audit Columns:** `create_uid` and `write_uid` refer to internal Odoo user IDs; ensure you join against the `res_users` table to resolve human-readable names.
- **Soft Deletes:** This table does not appear to implement a soft-delete flag; assume rows represent active or historically active definitions.
