# odoo_product_template_attribute_exclusion

## Source system
This table originates from Odoo ERP. The naming convention `product_template_attribute_exclusion` and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's internal ORM structure for managing product configuration constraints.

## Functional process 
This table supports the product configuration and variant management process. It defines rules that prevent specific combinations of product attributes from being selected together on a product template, ensuring that only valid product variants can be configured by users or customers in the sales/e-commerce pipeline.

## Description
One row in this table represents a single exclusion rule applied to a product template, identifying a specific attribute value that is incompatible with the template. This is a raw landing table representing the state of the Odoo `product.template.attribute.exclusion` model, used to facilitate the downstream construction of valid product variant matrices.
