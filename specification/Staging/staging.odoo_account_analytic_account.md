# odoo_account_analytic_account

## Source system
This table originates from Odoo ERP, specifically the accounting and analytic accounting module. The naming convention `account_analytic_account` and the presence of columns like `plan_id`, `partner_id`, and `company_id` are characteristic of Odoo's internal data structure for tracking costs and revenues across different dimensions.

## Functional process 
This table supports the financial reporting and cost-tracking process. It acts as the central repository for analytic accounts (also known as cost centers or project codes) used to categorize financial transactions for management accounting, distinct from the general ledger.

## Description
One row in this table represents a single analytic account used for tracking financial performance or project-based costs. This is a raw landing table in the Staging layer, containing the direct, un-transformed state of the Odoo analytic account records as extracted from the source database.

## Caveats for downstream consumers

- **Sensitive Data:** The `name` field may contain internal project names or sensitive client references.
- **Timezone:** Timestamps (`create_date`, `write_date`) are typically stored in UTC in Odoo, but verify against the source system configuration.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = TRUE` unless historical analysis is required.
- **JSONB:** The `name` column is `JSONB`; downstream consumers will need to extract the relevant language key (e.g., `name->>'en_US'`) to use it in reporting.
