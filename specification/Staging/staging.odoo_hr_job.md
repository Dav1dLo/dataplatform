# odoo_hr_job

## Source system
This table originates from Odoo, an open-source ERP system. The naming convention (`hr_job`, `create_uid`, `write_uid`, `JSONB` for translatable fields) is characteristic of Odoo's PostgreSQL-based backend architecture.

## Functional process 
This table supports the recruitment and human resources management process. It tracks job positions within the organization, including headcount planning (`expected_employees`), current staffing levels (`no_of_employee`), and recruitment targets (`no_of_recruitment`), facilitating workforce capacity planning and talent acquisition workflows.

## Description
One row in this table represents a single job position or role defined within the organization. It serves as a raw landed copy of the Odoo `hr.job` model, capturing the configuration, requirements, and status of specific job openings.

## Caveats for downstream consumers

- **JSONB Handling:** The `name` column contains JSONB data (e.g., `{"en_US": "Software Engineer"}`). Use `name->>'en_US'` to extract specific language values.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Ensure queries filter by `active = TRUE` unless historical/archived data is explicitly required.
- **Timestamps:** Timestamps are stored in UTC as per Odoo standard practice.
- **PII/Sensitive Data:** While this table contains job descriptions, ensure that any PII potentially embedded in `description` or `requirements` is handled according to your organization's data privacy policy.
