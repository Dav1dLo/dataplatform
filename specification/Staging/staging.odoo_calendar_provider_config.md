# odoo_calendar_provider_config

## Source system
This table originates from Odoo ERP, specifically the calendar integration module. The naming convention (e.g., `create_uid`, `write_date`, `cal_client_id`) is characteristic of Odoo's ORM-generated database schema.

## Functional process 
This table supports the external calendar synchronization process, managing authentication credentials and sync status for third-party calendar providers like Google Calendar and Microsoft Outlook. It acts as the configuration store for the Odoo calendar connector, enabling the system to authenticate against external APIs and toggle synchronization states.

## Description
One row in this table represents a single configuration record for an external calendar provider integration within the Odoo environment. It serves as a raw landed copy of the Odoo `calendar.provider.config` model, capturing the authentication secrets and operational flags required for calendar synchronization.
