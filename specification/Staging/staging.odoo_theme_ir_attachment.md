# odoo_theme_ir_attachment

## Source system
This table originates from Odoo ERP, specifically the `ir_attachment` model within the theme or website module. The naming convention `ir_attachment` (Internal Resource Attachment) is a standard Odoo pattern for managing files, assets, and binary data associated with website themes or system records.

## Functional process 
This table supports the website and theme management process by tracking metadata for file attachments used in Odoo themes. It links specific theme assets (such as CSS, images, or template files) to the system, facilitating the rendering of web pages and the management of theme-related static resources.

## Description
One row in this table represents a single file attachment record associated with an Odoo theme. It acts as a raw landing copy of the system's internal attachment metadata, capturing the file's identifier, its associated URL, and the audit trail of its creation and modification.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| create_uid | INTEGER | true | User ID who created the record | References `res.users`. |
| write_uid | INTEGER | true | User ID who last modified the record | References `res.users`. |
| name | VARCHAR | false | Display name of the attachment | Often the filename or descriptive label. |
| key | VARCHAR | false | Internal unique key | Used for theme asset identification. |
| url | VARCHAR | true | Public or internal URL path | Location of the asset file. |
| create_date | TIMESTAMP | true | Record creation timestamp | Inferred UTC based on Odoo standards. |
| write_date | TIMESTAMP | true | Last modification timestamp | Inferred UTC based on Odoo standards. |

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `create_uid` → `res_users.id`: Standard Odoo audit field referencing the creator.
    - `write_uid` → `res_users.id`: Standard Odoo audit field referencing the last modifier.
- **Natural keys (inferred):** 
    - `key`: In Odoo theme contexts, the `key` field is typically the unique business identifier for the asset.

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may need to be joined with user tables to resolve names; no direct PII is present in this table.
- **Timestamps:** Timestamps are assumed to be in UTC, as is standard for Odoo PostgreSQL deployments.
- **Data Integrity:** The `url` field may be null if the attachment is stored as a binary blob in the database rather than a file path.
- **Soft Deletes:** Odoo typically performs hard deletes on `ir_attachment` records; assume this table only contains currently active records unless an Odoo-specific `active` flag is present (which is absent here).
