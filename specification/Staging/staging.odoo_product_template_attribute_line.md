# odoo_product_template_attribute_line

## Source system
This table originates from Odoo ERP. The naming convention `product_template_attribute_line` and the presence of Odoo-specific audit columns like `create_uid`, `write_uid`, and `sequence` are characteristic of the Odoo ORM's underlying database schema for managing product variants and configurable attributes.

## Functional process 
This table supports the product configuration and variant management process. It links specific product templates to attributes (e.g., "Color" or "Size") that define the available variations for a product, facilitating the generation of product variants in the e-commerce and inventory modules.

## Description
One row in this table represents a single attribute line assigned to a product template, defining which attribute is available for that product. This is a raw landed copy from the Odoo staging layer, intended to be used as a source for building product dimension models.

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `product_tmpl_id` → `product_template.id`: Links the attribute line to the specific product template.
    - `attribute_id` → `product_attribute.id`: Links to the master definition of the attribute.
- **Natural keys (inferred):** 
    - `(product_tmpl_id, attribute_id)`: In Odoo, a product template typically cannot have the same attribute defined more than once.

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may map to internal employee records; ensure these are handled according to internal data privacy policies.
- **Timezone:** Timestamps are stored in the server's local time; verify the Odoo instance timezone configuration (usually UTC) before performing time-series analysis.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless performing historical audit or recovery analysis.
- **Data Integrity:** As this is a raw staging table, it may contain orphaned records if the source system's referential integrity was not strictly enforced during the extraction process.
