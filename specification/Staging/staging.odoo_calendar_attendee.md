# odoo_calendar_attendee

## Source system
This table originates from Odoo ERP, specifically the calendar module. The naming convention (`odoo_calendar_attendee`) and the presence of Odoo-specific audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) strongly indicate this is a direct extraction of the `calendar.attendee` model from an Odoo PostgreSQL database.

## Functional process 
This table supports the scheduling and meeting management process within the Odoo platform. It tracks the participation status of individual partners (users or contacts) invited to specific calendar events, managing their RSVP state and availability status for resource planning.

## Description
One row in this table represents a single attendee's association with a specific calendar event. It acts as a raw landing copy of the Odoo `calendar.attendee` table, capturing the invitation state and metadata for each participant at the grain of one row per attendee per event.
