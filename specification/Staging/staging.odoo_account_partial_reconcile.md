# odoo_account_partial_reconcile

## Source system
This table originates from Odoo ERP, specifically the accounting module. The naming convention `account_partial_reconcile` and the presence of `move_id` references are characteristic of Odoo's double-entry accounting ledger structure, where partial reconciliations link debit and credit journal items that do not fully offset each other.

## Functional process 
This table supports the financial reconciliation process, specifically tracking partial matches between journal items. It is used to calculate outstanding balances for invoices and payments, ensuring that the ledger accurately reflects which portions of a transaction have been settled and which remain open.

## Description
One row in this table represents a single partial reconciliation event between a debit journal item and a credit journal item. It acts as a raw landed copy of the Odoo `account.partial.reconcile` model, capturing the specific amount matched and the associated currency impacts at the time of the reconciliation.
