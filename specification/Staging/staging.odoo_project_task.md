# odoo_project_task

## Source system
This table originates from Odoo, an open-source ERP and CRM platform. The naming convention (e.g., `create_uid`, `write_date`, `partner_id`) and the presence of Odoo-specific fields like `html_field_history` and `task_properties` (JSONB) are characteristic of the Odoo `project.task` model.

## Functional process 
This table supports the Project Management and Service Delivery business processes. It tracks individual tasks within projects, managing their lifecycle from assignment to completion, including resource allocation, deadline tracking, and integration with sales orders for billable work.

## Description
One row represents a single task within a project, capturing its current state, assigned resources, and temporal metadata. This table serves as a raw landed copy of the Odoo `project.task` model, providing the base data for project performance reporting and resource utilization analysis.

## Caveats for downstream consumers

- **Sensitive Data:** Contains `email_cc`, `email_from`, and `partner_phone`. Ensure these are masked if exposing to non-authorized users.
- **Timestamps:** All `TIMESTAMP` fields are stored in UTC by Odoo.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless performing historical analysis.
- **Denormalization:** Several `partner_*` fields are denormalized from the `res_partner` table; these may become stale if the partner record is updated.
- **JSONB:** `task_properties` and `html_field_history` contain unstructured data; use PostgreSQL JSONB operators for extraction.
