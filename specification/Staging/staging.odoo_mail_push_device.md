# odoo_mail_push_device

## Source system
This table originates from Odoo ERP, as evidenced by the naming convention (`mail_push_device`), the use of `partner_id` (the standard Odoo identifier for contacts/users), and the presence of `create_uid`/`write_uid` audit columns which are characteristic of Odoo's ORM framework.

## Functional process 
This table supports the push notification infrastructure for Odoo's messaging system. It stores registration details for client devices (such as browsers or mobile apps) that have opted in to receive web push notifications, linking these devices to specific partners (users) within the system.

## Description
One row represents a single registered push notification device associated with a specific partner. It acts as a raw landing copy of the Odoo `mail.push.device` model, capturing the endpoint URL, encryption keys, and expiration metadata required to send push messages to the client.
