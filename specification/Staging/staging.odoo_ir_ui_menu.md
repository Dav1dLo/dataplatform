# odoo_ir_ui_menu

## Source system
This table originates from Odoo ERP, specifically the `ir.ui.menu` model within the Odoo framework. The naming convention (`ir_ui_menu`) and the presence of Odoo-specific audit columns like `create_uid`, `write_uid`, and `parent_path` (used for materialized path trees in Odoo) are definitive indicators of an Odoo PostgreSQL backend.

## Functional process 
This table supports the application's navigation and user interface structure. It defines the menu hierarchy, including the display order (`sequence`), parent-child relationships (`parent_id`), and the associated actions triggered when a user interacts with a menu item.

## Description
One row represents a single menu item within the Odoo application interface. This table serves as a raw landing copy of the system's menu configuration, capturing the hierarchical structure and metadata required to render the navigation tree. It is used to map user permissions and interface visibility to specific business actions.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| sequence | INTEGER | true | Display order index | Lower numbers appear first in the UI. |
| parent_id | INTEGER | true | Self-referencing FK to `id` | Defines the menu hierarchy. |
| create_uid | INTEGER | true | Creator user ID | FK to `res_users.id`. |
| write_uid | INTEGER | true | Last modifier user ID | FK to `res_users.id`. |
| parent_path | VARCHAR | true | Materialized path | String representation of the tree path (e.g., "1/5/12"). |
| web_icon | VARCHAR | true | Icon identifier | Path or class name for the menu icon. |
| action | VARCHAR | true | Associated action | Reference to the action triggered by the menu. |
| name | JSONB | false | Menu display name | Multi-language support via JSON structure. |
| active | BOOLEAN | true | Soft-delete flag | If false, the menu is hidden from the UI. |
| create_date | TIMESTAMP | true | Record creation timestamp | UTC assumed. |
| write_date | TIMESTAMP | true | Last modification timestamp | UTC assumed. |

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `parent_id` → `staging.odoo_ir_ui_menu.id`: Represents the parent node in the navigation tree.
    - `create_uid` → `staging.odoo_res_users.id` (guess): Tracks the user who created the menu entry.
    - `write_uid` → `staging.odoo_res_users.id` (guess): Tracks the user who last modified the menu entry.
- **Natural keys (inferred):** Not confidently inferable; Odoo typically relies on the surrogate `id` for menu management.

## Caveats for downstream consumers

- **PII/Sensitivity:** Contains no direct PII, but `create_uid` and `write_uid` link to user identities.
- **Timestamps:** Timestamps are stored in the server's local time (typically UTC in Odoo deployments); verify against the source instance configuration.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless auditing historical menu structures.
- **JSONB:** The `name` column is a `JSONB` object; downstream consumers will need to use `->>` or `jsonb_extract_path_text` to retrieve specific language strings.
