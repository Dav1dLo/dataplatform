# odoo_website_controller_page

## Source system
This table originates from Odoo ERP, specifically the website module. The naming convention (e.g., `website_id`, `view_id`, `create_uid`, `write_uid`) and the presence of Odoo-standard audit fields (`create_date`, `write_date`) are characteristic of Odoo's internal ORM structure for managing website controller pages.

## Functional process 
This table supports the website content management process, specifically tracking the configuration and publication status of dynamic website pages handled by controllers. It links specific website views to domain records, enabling the dynamic rendering of content based on URL slugs and domain filters.

## Description
One row in this table represents a single website controller page configuration within the Odoo environment. It acts as a raw landed copy of the Odoo `website.controller.page` model, capturing the mapping between a view, its associated record domain, and its publication status.

## Caveats for downstream consumers

- **PII/Sensitive Data:** Contains `create_uid` and `write_uid`, which link to user identities; ensure these are handled according to internal access policies.
- **Timestamps:** All `_date` fields are assumed to be in UTC, consistent with Odoo's standard database storage.
- **Soft Deletes:** This table represents a raw landing of Odoo data; it does not explicitly implement soft deletes. If a record is deleted in the source Odoo instance, it may disappear from this table upon the next full refresh.
- **Data Quality:** `record_domain` contains Odoo domain syntax (e.g., `[('active', '=', True)]`), which requires specialized parsing if used for downstream filtering.
