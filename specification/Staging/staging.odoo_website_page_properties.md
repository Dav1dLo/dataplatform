# odoo_website_page_properties

## Source system
This table originates from Odoo ERP, specifically the website module. The naming convention (`website_page_properties`) and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's internal ORM structure for managing website-specific metadata and URL redirection history.

## Functional process 
This table supports the website content management process, specifically tracking properties and URL history for pages within the Odoo website builder. It is used to maintain mappings between legacy URLs and current page configurations, ensuring that site navigation and SEO redirects remain intact during content updates.

## Description
One row in this table represents a specific property configuration or URL mapping record associated with a website page. It serves as a raw landed copy of the Odoo `website.page.properties` model, capturing the state of page metadata and historical URL references at the time of ingestion.

## Caveats for downstream consumers

- **Timestamps:** All `_date` columns are assumed to be in UTC, consistent with standard Odoo database configurations.
- **PII:** The table does not contain direct PII, but `create_uid` and `write_uid` link to user identities in the `res_users` table, which may contain sensitive information.
- **Data Integrity:** As a staging table, this represents a raw snapshot; expect potential duplicates or partial records if the ingestion process is interrupted.
- **Soft Deletes:** Odoo typically uses `active` flags for soft deletes; since no `active` column is present, this table likely contains only active records or the full history depending on the extraction logic.
