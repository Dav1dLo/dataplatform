# odoo_calendar_event

## Source system
This table originates from Odoo ERP, specifically the calendar module. The naming conventions (`res_id`, `res_model`, `create_uid`, `write_uid`) and the specific column pattern for recurring events (`recurrence_id`, `recurrency`) are characteristic of the Odoo ORM structure.

## Functional process 
This table supports the scheduling and time-management business process, tracking meetings, appointments, and internal calendar events. It links calendar entries to other business entities (such as CRM opportunities via `opportunity_id` or other models via `res_id`) to provide a unified view of time-bound activities across the organization.

## Description
One row in this table represents a single calendar event or a specific occurrence within a recurring series. It serves as a raw landed copy of the Odoo `calendar.event` model, capturing event metadata, timing, and associations with other system records.

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):**
    - `user_id` → `res_users.id` (Standard Odoo pattern for record ownership).
    - `opportunity_id` → `crm_lead.id` (Links event to specific sales opportunities).
    - `recurrence_id` → `calendar_recurrence.id` (Links to the definition of the recurring series).
- **Natural keys (inferred):** Not confidently inferable. Odoo typically relies on the surrogate `id` for internal linking.

## Caveats for downstream consumers

- **Sensitive Data:** The `description` and `name` columns may contain PII or sensitive business discussions.
- **Timezones:** Timestamps (`start`, `stop`, `create_date`, `write_date`) are typically stored in UTC in Odoo; verify against system configuration.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless performing audit/historical analysis.
- **Data Grain:** This table contains both individual events and potentially recurring instances; ensure logic accounts for `recurrency` flags to avoid double-counting.
