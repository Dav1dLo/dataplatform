# odoo_hr_skill_level

## Source system
This table originates from Odoo ERP, specifically the Human Resources module. The naming convention (`hr_skill_level`) and the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's internal ORM structure.

## Functional process 
This table supports the Skills Management process within the HR module, defining the proficiency levels associated with specific skill types (e.g., "Beginner", "Intermediate", "Expert" for a "Programming" skill type). It allows the organization to quantify employee competency through the `level_progress` metric.

## Description
One row represents a single proficiency level definition within a specific skill category. It serves as a raw landed copy of the Odoo `hr.skill.level` model, capturing the configuration of skill levels used to evaluate employee capabilities.
