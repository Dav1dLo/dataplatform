# odoo_hr_skill_type

## Source system
This table originates from Odoo ERP, specifically the Human Resources module. The naming convention (`hr_skill_type`) and the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's PostgreSQL schema structure.

## Functional process 
This table supports the HR competency management process by defining categories or "types" of skills (e.g., "Technical Skills", "Languages", "Soft Skills") that can be assigned to employees. It acts as a configuration lookup table that groups individual skill definitions under a common classification.

## Description
One row represents a single skill category or type within the HR system. This is a raw landed copy of the Odoo `hr_skill_type` table, serving as the base staging entity for downstream competency reporting and employee profile enrichment.

## Caveats for downstream consumers

- **PII/Sensitive Data:** None identified; this table contains configuration metadata.
- **Timestamps:** Assumed to be in UTC, consistent with Odoo's internal storage.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; queries should generally filter by `WHERE active = TRUE` unless performing historical audits.
- **JSONB Handling:** The `name` column is a `JSONB` object. Downstream consumers will need to extract the relevant language key (e.g., `name->>'en_US'`) to retrieve a human-readable string.
