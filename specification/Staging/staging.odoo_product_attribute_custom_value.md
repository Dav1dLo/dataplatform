# odoo_product_attribute_custom_value

## Source system
This table originates from Odoo ERP. The naming convention `product_attribute_custom_value` and the presence of `create_uid`, `write_uid`, and `*_id` suffix patterns are characteristic of Odoo's internal ORM structure, which tracks custom attribute values assigned to product lines in sales or point-of-sale transactions.

## Functional process 
This table supports the product configuration and sales order process. It captures user-defined values for product attributes (e.g., custom text engravings or specific user-provided configurations) that are linked to individual lines within sales orders or point-of-sale orders.

## Description
One row represents a single custom attribute value entry associated with a specific product line in a sales or POS transaction. It serves as a raw landing copy of the Odoo `product.attribute.custom.value` model, providing the link between custom configuration data and the corresponding order line.
