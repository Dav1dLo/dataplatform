## Functional process 
This table supports the HR contract management process by defining the various categories of employment contracts available within the organization (e.g., "Permanent", "Temporary", "Internship"). It is used to classify employee contracts for payroll, legal compliance, and reporting purposes.

## Description
One row in this table represents a single contract type definition used to categorize employment agreements. This is a raw landed copy of the Odoo `hr_contract_type` table, serving as the staging entity for downstream HR analytics and reporting.
