# odoo_res_country

## Source system
This table originates from Odoo ERP, specifically the `res_country` model. The naming convention (e.g., `res_country`, `create_uid`, `write_uid`, `jsonb` fields for multi-language support) is characteristic of the Odoo framework's core metadata tables.

## Functional process 
This table supports the global address and localization management process. It defines the master list of countries used across the ERP for customer addresses, tax calculations (via `vat_label`), and regional formatting requirements (via `address_format` and `zip_required`).

## Description
One row in this table represents a single country entity defined within the Odoo system. This is a raw landing table in the staging layer, containing the base configuration for countries, including their international calling codes, VAT labeling requirements, and address display templates.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| address_view_id | INTEGER | true | Foreign key to address view | Links to a specific UI view for address formatting. |
| currency_id | INTEGER | true | Foreign key to currency | The default currency associated with the country. |
| phone_code | INTEGER | true | International dialing prefix | Numeric country calling code. |
| create_uid | INTEGER | true | Creator user ID | ID of the user who created the record. |
| write_uid | INTEGER | true | Last modifier user ID | ID of the user who last updated the record. |
| code | VARCHAR(2) | false | ISO 3166-1 alpha-2 code | Standard two-letter country code. |
| name_position | VARCHAR | true | Name display position | Configuration for how the name is rendered. |
| name | JSONB | false | Country name | Multi-language support; contains localized names. |
| vat_label | JSONB | true | VAT label | Multi-language support; label for tax ID fields. |
| address_format | TEXT | true | Address template | Jinja2-style template for formatting addresses. |
| state_required | BOOLEAN | true | State field requirement | Flag indicating if a state/province is mandatory. |
| zip_required | BOOLEAN | true | Zip code requirement | Flag indicating if a postal code is mandatory. |
| create_date | TIMESTAMP | true | Creation timestamp | Recorded in server local time. |
| write_date | TIMESTAMP | true | Last update timestamp | Recorded in server local time. |

- **Foreign keys (inferred):** 
    - `currency_id` → `staging.res_currency.id` (Likely reference to the currency master table).
    - `create_uid` / `write_uid` → `staging.res_users.id` (Standard Odoo pattern for tracking record ownership).
- **Natural keys (inferred):** 
    - `code` (The ISO 3166-1 alpha-2 code is the unique business identifier for countries).

## Caveats for downstream consumers

- **JSONB Handling:** The `name` and `vat_label` columns contain JSONB data; use PostgreSQL `->>` operator to extract text values for reporting.
- **Timezone:** Timestamps (`create_date`, `write_date`) are stored in the Odoo server's local time, which may not be UTC.
- **Data Integrity:** This is a raw staging table; it may contain historical records or soft-deleted entries if the Odoo instance uses such patterns, though Odoo typically performs hard deletes on master data.
- **PII/Sensitivity:** No direct PII, but `create_uid` and `write_uid` link to internal user identities.
