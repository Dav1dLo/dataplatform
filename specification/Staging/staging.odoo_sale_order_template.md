# odoo_sale_order_template

## Source system
This table originates from Odoo ERP, a modular business management software. The naming convention (`odoo_sale_order_template`) and specific column patterns (e.g., `create_uid`, `write_uid`, `company_id`, `JSONB` fields for journals) are characteristic of Odoo's PostgreSQL-based backend architecture.

## Functional process 
This table supports the sales quotation management process by storing predefined templates for sale orders. These templates allow users to standardize terms, payment requirements, and automated email communications, streamlining the creation of recurring or common sales documents within the lead-to-cash pipeline.

## Description
One row in this table represents a single sale order template configuration used to pre-populate sales quotations. It serves as a raw landed copy of the Odoo `sale.order.template` model, capturing settings such as signature requirements, payment terms, and associated email templates.

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may link to employee names in other tables.
- **Timestamps:** Assumed to be in UTC, consistent with Odoo's standard database storage.
- **Soft Deletes:** The `active` column should be used to filter out inactive templates; do not assume all rows are currently in use.
- **JSONB:** The `note` and `journal_id` columns contain semi-structured data; ensure your downstream processing handles potential schema evolution within these fields.
