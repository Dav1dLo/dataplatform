# odoo_stock_warehouse_orderpoint

## Source system
This table originates from Odoo ERP, specifically the Inventory/Warehouse management module. The naming convention `stock_warehouse_orderpoint` and the presence of columns like `product_min_qty`, `product_max_qty`, and `bom_id` are characteristic of Odoo's internal data structures for managing automated replenishment rules.

## Functional process 
This table supports the inventory replenishment and procurement process. It defines the "Reordering Rules" (Orderpoints) that trigger automatic creation of purchase orders or manufacturing orders when stock levels for a specific product fall below the defined minimum threshold within a designated warehouse or location.

## Description
One row in this table represents a single reordering rule for a specific product at a specific warehouse location. It acts as a raw landed copy of the Odoo `stock.warehouse.orderpoint` model, capturing the configuration parameters that drive automated supply chain replenishment logic.

## Caveats for downstream consumers

- **Sensitive Data:** No direct PII, but contains internal operational logic and vendor relationships.
- **Timestamps:** Assumed to be in UTC, consistent with Odoo's standard database storage.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should filter by `WHERE active = TRUE` to retrieve only currently valid rules.
- **Precision:** `NUMERIC` types are used for quantities; ensure downstream systems handle decimal precision correctly to avoid rounding errors in replenishment calculations.
