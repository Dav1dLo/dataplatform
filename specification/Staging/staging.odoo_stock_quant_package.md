# odoo_stock_quant_package

## Source system
This table originates from Odoo ERP, specifically the Inventory/Warehouse management module. The naming convention `odoo_stock_quant_package` and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's internal ORM-mapped tables.

## Functional process 
This table supports the inventory management and logistics process, specifically tracking physical packaging units (e.g., pallets, boxes, or containers) within a warehouse. It facilitates the grouping of stock quant records into logical packages for shipping, storage, or internal movement.

## Description
One row represents a single physical or logical package unit within the Odoo inventory system. This is a raw landed copy of the Odoo `stock.quant.package` model, capturing metadata such as the package name, associated location, shipping weight, and audit timestamps.

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may need to be joined with an employee/user table to resolve names.
- **Timestamps:** All `create_date` and `write_date` values are stored in UTC as per standard Odoo behavior.
- **Soft Deletes:** Odoo typically uses hard deletes for this model; however, check for the absence of an `active` boolean column, which is common in other Odoo tables for soft-deletion.
- **Precision:** `shipping_weight` is a `DOUBLE PRECISION` type; ensure rounding is applied if aggregating for financial or regulatory reporting.
