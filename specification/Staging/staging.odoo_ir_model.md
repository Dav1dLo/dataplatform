# odoo_ir_model

## Source system
This table originates from Odoo ERP, specifically the `ir.model` system table. The naming convention (prefix `ir_`) and the presence of Odoo-specific columns like `is_mail_thread` and `website_form_key` are characteristic of the Odoo internal metadata schema used to manage object-relational mapping (ORM) definitions.

## Functional process 
This table supports the Odoo framework's internal metadata management, specifically the definition and configuration of data models (objects) within the system. It tracks which models exist, their display names, their persistence state (transient vs. persistent), and their integration with Odoo's mail and website form modules.

## Description
One row in this table represents a single data model definition registered within the Odoo application. It acts as a raw landed copy of the system's internal model registry, capturing the configuration and behavioral flags for each entity.
