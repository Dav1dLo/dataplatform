## Functional process 
This table supports the Sales Quotation Template process, specifically managing optional products associated with a template. It allows businesses to define cross-sell or upsell items that can be added to a quotation when a specific template is selected, linking products to templates with defined quantities and units of measure.

## Description
One row in this table represents a single optional product configuration linked to a specific sales order template. It acts as a raw landing copy of the Odoo database table, capturing the relationship between a template, a product, and the requested quantity.
