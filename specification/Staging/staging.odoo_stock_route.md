# odoo_stock_route

## Source system
This table originates from Odoo ERP, specifically the Inventory/Warehouse management module. The naming convention (`odoo_stock_route`) and the presence of Odoo-specific audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) and JSONB fields for multi-language names are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the supply chain and logistics configuration process, specifically defining "Routes" for stock movement. These routes dictate how products move between locations or warehouses (e.g., "Buy," "Make to Order," or "Dropship"). The `selectable` boolean flags determine where these routes can be applied within the Odoo UI (e.g., on specific products, categories, or warehouse configurations).

## Description
One row in this table represents a single stock routing rule or configuration path within the Odoo inventory system. This is a raw landing copy of the Odoo `stock_route` table, capturing the configuration state of logistics paths at the grain of one route per row.

## Caveats for downstream consumers

- **JSONB Handling:** The `name` column is `JSONB`. Query writers must use the `->>` operator to extract text (e.g., `name->>'en_US'`).
- **Timestamps:** Timestamps are stored in the Odoo application time (typically UTC), but verify against the `res_company` timezone settings if local time is required.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Ensure queries filter by `WHERE active = TRUE` unless historical/archived routes are explicitly required.
- **Data Sensitivity:** No direct PII is present, but `create_uid` and `write_uid` link to internal user identities.
