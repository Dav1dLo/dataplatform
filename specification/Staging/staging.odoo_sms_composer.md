## Source system

## Functional process 
This table supports the SMS communication and marketing automation process within Odoo. It acts as a transient or persistent record of SMS composition sessions, tracking the configuration of SMS messages, the target models (e.g., customers, leads), and the specific content being prepared for dispatch.

## Description
One row in this table represents a single SMS composition event or draft within the Odoo system. It captures the state of an SMS message before or during the sending process, including the message body, target recipient identifiers, and configuration flags for mass mailing. This is a raw landing of the Odoo `sms.composer` model, intended for auditing communication attempts or reconstructing marketing campaign history.
