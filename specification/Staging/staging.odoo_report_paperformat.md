# odoo_report_paperformat

## Source system
This table originates from Odoo ERP, as evidenced by the naming convention `report_paperformat` and the presence of standard Odoo audit columns such as `create_uid`, `write_uid`, `create_date`, and `write_date`. The table structure is characteristic of Odoo's internal configuration management for PDF report generation.

## Functional process 
This table supports the document generation and reporting module within Odoo. It stores the configuration settings for paper formats (e.g., A4, Letter, custom dimensions) used when rendering PDF reports, ensuring consistent layout, margins, and orientation across different business documents like invoices, purchase orders, and delivery slips.

## Description
One row in this table represents a single paper format configuration profile used by the Odoo reporting engine. This is a raw landed copy of the Odoo `report_paperformat` model, serving as the staging layer source for downstream reporting dimensions that define document layout properties.

## Caveats for downstream consumers

- **Sensitive Data:** Contains no PII or financial data; safe for general access.
- **Timestamps:** `create_date` and `write_date` are stored in UTC by Odoo.
- **Soft Deletes:** This table does not implement soft deletes; records are physically removed if deleted in the source.
- **Units:** All dimension columns (`page_height`, `page_width`, `margin_*`) are measured in millimeters.
- **Precision:** `VARCHAR` columns do not have defined lengths in the metadata; downstream systems should handle variable-length strings appropriately.
