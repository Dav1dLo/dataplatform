# odoo_discuss_channel

## Source system
This table originates from Odoo ERP, specifically the Discuss module. The naming convention (`discuss_channel`), the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`), and the `sfu_` (Selective Forwarding Unit) prefix for video/audio conferencing metadata are characteristic of Odoo's internal communication and collaboration framework.

## Functional process 
This table supports the internal communication and collaboration infrastructure within Odoo. It manages the definition and configuration of chat channels, including direct messages, group chats, and public channels, as well as the integration with real-time video/audio conferencing services via the SFU columns.

## Description
One row represents a single communication channel or chat room within the Odoo Discuss module. It tracks the channel's configuration, its hierarchical relationship to other channels, and its active status. This table serves as a raw landed copy of the Odoo `mail.channel` model, providing the base entity for downstream communication analytics.

## Caveats for downstream consumers

- **Sensitive Data:** The `name` and `description` fields may contain sensitive project names or internal discussions; ensure appropriate masking if exposing to non-authorized users.
- **Timestamps:** All `_date` and `_dt` columns are assumed to be in UTC, consistent with Odoo's standard database storage.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless performing historical audits.
- **Data Precision:** `VARCHAR` columns without explicit lengths (e.g., `name`, `channel_type`) are Odoo-standard; downstream systems should allocate sufficient buffer (e.g., 255 characters) to avoid truncation.
