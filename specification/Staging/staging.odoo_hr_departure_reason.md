## Functional process 
This table supports the offboarding and employee lifecycle management process. It stores the standardized list of reasons for employee departures (e.g., resignation, termination, retirement), which are used to categorize exit data for HR reporting and analytics.

## Description
One row represents a single defined reason for an employee's departure from the organization. It serves as a reference lookup table within the staging layer, providing localized labels for departure categories used by the HR module.
