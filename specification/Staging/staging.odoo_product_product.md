# odoo_product_product

## Source system
This table originates from Odoo ERP, as evidenced by the naming convention (`product_product`, `product_tmpl_id`, `create_uid`, `write_uid`) and the specific use of Odoo-standard fields like `default_code` (internal reference) and `combination_indices`.

## Functional process 
This table supports the Product Lifecycle Management and Inventory Management processes. It represents the specific variants of products (e.g., a specific size/color combination) that are tracked in inventory, distinct from the generic product template.

## Description
One row represents a single product variant within the Odoo product catalog. This is a raw landed copy of the Odoo `product.product` model, serving as the base staging entity for downstream product dimension modeling.

## Caveats for downstream consumers

- **Sensitive Data:** No direct PII, but `standard_price` may contain commercially sensitive cost information.
- **Timestamps:** Assumed to be in UTC, as is standard for Odoo PostgreSQL databases.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = true` unless historical/archived data is required.
- **JSONB:** `standard_price` and `lot_properties_definition` require PostgreSQL JSONB operators (e.g., `->>`) for extraction.
- **Precision:** `NUMERIC` types for weight and volume do not have defined scale/precision in the metadata; verify against source DDL if high-precision calculations are required.
