## Functional process 
This table supports the warehouse storage optimization process, specifically defining capacity constraints for storage categories. It tracks how much of a specific product or package type can be stored within a defined storage category, enabling the system to validate warehouse slotting and replenishment logic.

## Description
One row in this table represents a specific capacity constraint rule for a storage category, defined either by a specific product or a package type. This is a raw landed copy of the Odoo `stock.storage.category.capacity` model, serving as the staging layer entity for warehouse capacity configuration.
