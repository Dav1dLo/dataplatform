# odoo_mrp_consumption_warning

## Source system
This table originates from Odoo ERP, specifically the Manufacturing (MRP) module. The naming convention `mrp_consumption_warning` and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's internal ORM-managed tables.

## Functional process 
This table supports the manufacturing execution process, specifically tracking warnings or alerts generated during the consumption of raw materials for production orders. It likely logs instances where material usage deviates from the expected bill of materials (BOM) quantities, triggering a notification or validation step for the production manager.

## Description
One row in this table represents a single consumption warning event associated with a manufacturing order. As a staging table, it serves as a raw, landed copy of the Odoo database record, capturing the audit trail of who created or modified the warning record and when.
