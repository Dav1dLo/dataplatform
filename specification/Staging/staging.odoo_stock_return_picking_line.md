# odoo_stock_return_picking_line

## Source system
This table originates from Odoo ERP, specifically the Inventory/Warehouse management module. The naming convention `stock_return_picking_line` and the presence of `wizard_id` and `move_id` are characteristic of Odoo's internal ORM structures used to manage return workflows.

## Functional process 
This table supports the inventory return process, specifically tracking individual line items included in a return picking wizard. It captures which products are being returned, the quantities involved, and whether the return should trigger a financial refund, facilitating the reconciliation between warehouse movements and accounting.

## Description
One row represents a single line item within a stock return wizard, detailing the quantity of a specific product being returned. As a staging table, it provides a raw, landed copy of the Odoo `stock.return.picking.line` model, serving as the foundation for downstream inventory and return reporting.
