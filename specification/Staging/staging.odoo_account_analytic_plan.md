## Functional process 
This table supports the management of analytic accounting structures, which allow businesses to track costs and revenues across different dimensions (e.g., projects, departments, or cost centers). It defines the hierarchy and configuration of analytic plans, determining how analytic accounts are grouped and applied within the financial reporting pipeline.

## Description
One row represents a single analytic plan or a node within an analytic plan hierarchy. This table serves as a raw landed copy of the Odoo `account.analytic.plan` model, capturing the structural configuration and metadata for analytic accounting dimensions.
