This table originates from Odoo, an open-source ERP and business management suite. ## Functional process 
This table supports the communication and collaboration module within Odoo, specifically tracking metadata associated with voice or audio attachments. It links audio files (via `attachment_id`) to the users who created or modified the record, facilitating the management of voice messages or call recordings within the platform's chat interface.

## Description
One row in this table represents the metadata record for a specific voice or audio attachment within the Odoo Discuss module. This is a raw landed copy of the source system's metadata table, intended to provide a historical audit trail of voice message creation and updates.
