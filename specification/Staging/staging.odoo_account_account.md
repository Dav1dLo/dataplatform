# odoo_account_account

## Source system
This table originates from Odoo ERP, specifically the accounting module. The naming convention `odoo_account_account` and the presence of Odoo-specific audit columns like `create_uid`, `write_uid`, and `reconcile` are characteristic of the Odoo `account.account` model.

## Functional process 
This table supports the Chart of Accounts management process within the financial accounting module. It defines the structure of the general ledger, categorizing financial transactions into specific accounts (e.g., assets, liabilities, equity, income, expenses) and determining whether those accounts allow for reconciliation or are deprecated.

## Description
One row represents a single general ledger account definition within the Odoo accounting system. This is a raw landed copy of the Odoo `account.account` model, serving as the primary source for financial reporting and account classification in the staging layer.
