## Source system
This table likely originates from the Odoo ERP system, given the naming convention `odoo_` and common accounting table names like `account_account`. Odoo is a popular suite of open-source business management software.

This table represents the chart of accounts within an accounting system. It supports core accounting functions such as financial reporting, transaction categorization, and general ledger management.

## Description
This table contains a list of all accounts used in the company's chart of accounts. Each row represents a single account, detailing its type, name, and other relevant accounting properties. This is a raw landing table, providing a direct copy of the account data from the Odoo system.
