# odoo_ir_model_relation

## Source system
This table originates from Odoo ERP. The naming convention `ir_model_relation` is specific to the Odoo internal registry (IR) schema, which manages the metadata and structural relationships between database models and modules within the Odoo framework.

## Functional process 
This table supports the Odoo system's internal metadata management, specifically tracking the relationships between data models (`model`) and the modules (`module`) that define or extend them. It is part of the core framework's dependency and structure tracking, ensuring that the system understands which modules are responsible for which data structures.

## Description
One row in this table represents a single relationship link between a specific Odoo data model and a module. It serves as a raw landed copy of the Odoo `ir_model_relation` system table, capturing the structural metadata required for the application to resolve dependencies and model definitions.

- **Timestamps:** All `create_date` and `write_date` values are assumed to be in UTC, consistent with standard Odoo database configurations.
- **Data Integrity:** As a staging table, this contains raw Odoo system data; ensure that joins to `ir_model` or `ir_module` account for potential missing records if the staging layer is not fully synchronized.
- **Soft Deletes:** Odoo typically performs hard deletes on metadata tables; assume this table contains only active records unless otherwise specified by the source system's configuration.
