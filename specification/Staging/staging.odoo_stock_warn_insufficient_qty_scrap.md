# odoo_stock_warn_insufficient_qty_scrap

## Source system
This table originates from Odoo ERP, specifically the inventory management module. The naming convention `stock_warn_insufficient_qty_scrap` and the presence of columns like `product_id`, `location_id`, and `product_uom_name` are characteristic of Odoo's internal stock warning wizards used during the scrap process.

## Functional process 
This table supports the inventory management and quality control process, specifically tracking warnings generated when a user attempts to scrap a quantity of a product that exceeds the available stock in a specific location. It acts as a transient or logging record for the "Insufficient Quantity" wizard during the scrap workflow.

## Description
One row in this table represents a single warning event triggered when a scrap request fails due to insufficient stock levels. It captures the product, the intended location, the requested quantity, and the associated scrap operation attempt. As a staging table, it serves as a raw landed copy of the Odoo database state for audit and reporting purposes.
