# odoo_ir_model_fields_selection

## Source system
This table originates from Odoo ERP. The naming convention `ir_model_fields_selection` is a standard internal Odoo table structure used to store the selection options (dropdown values) for fields defined within the Odoo metadata framework.

## Functional process 
This table supports the metadata management and configuration process within Odoo. It defines the valid selectable values for specific fields across the system, ensuring that UI components and data validation logic remain consistent with the underlying model definitions.

## Description
One row in this table represents a single selectable option for a specific field within an Odoo model. This is a raw landed copy of the Odoo system table, serving as a reference for mapping internal selection keys to their human-readable labels.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| field_id | INTEGER | false | Foreign key to `ir_model_fields` | Links the selection option to the parent field definition. |
| sequence | INTEGER | true | Display order | Determines the sort order of options in the UI. |
| create_uid | INTEGER | true | Creator user ID | References the user who created this record. |
| write_uid | INTEGER | true | Last modifier user ID | References the user who last updated this record. |
| value | VARCHAR | false | Internal selection key | The actual value stored in the database for this option. |
| name | JSONB | false | Display label | The human-readable label, often localized via JSONB. |
| create_date | TIMESTAMP | true | Creation timestamp | Recorded in UTC by the Odoo application. |
| write_date | TIMESTAMP | true | Last update timestamp | Recorded in UTC by the Odoo application. |

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `field_id` → `staging.ir_model_fields.id`: This column links the selection option to the specific field definition it belongs to.
    - `create_uid` → `staging.res_users.id` (guess): Standard Odoo pattern for tracking record creation.
    - `write_uid` → `staging.res_users.id` (guess): Standard Odoo pattern for tracking record modification.
- **Natural keys (inferred):** 
    - (`field_id`, `value`): In Odoo, a specific field cannot have duplicate internal values for its selection set.

## Caveats for downstream consumers

- **Localization:** The `name` column is `JSONB`, which likely contains multi-language labels. Ensure your queries handle JSON extraction (e.g., `name->>'en_US'`) to get the desired language.
- **Timestamps:** Timestamps are assumed to be in UTC, consistent with Odoo's internal storage format.
- **Data Integrity:** As this is a raw staging table, it may contain historical records or orphaned entries if the upstream `ir_model_fields` table has been purged.
- **Sensitivity:** No PII is expected in this metadata table, but `create_uid` and `write_uid` link to user identities.
