# odoo_ir_module_module

## Source system
This table originates from Odoo ERP, an open-source business management software. The naming convention `ir_module_module` is a standard internal Odoo table name used to track installed and available application modules within the Odoo framework.

## Functional process 
This table supports the application lifecycle management and module registry process within the Odoo environment. It tracks which modules are installed, their versioning, licensing, and metadata, facilitating the administration of system features and extensions.

## Description
One row in this table represents a single Odoo module (application or plugin) registered within the system. This is a raw landed copy of the Odoo `ir_module_module` table, capturing the state, metadata, and configuration of modules at the time of ingestion.

## Caveats for downstream consumers

- **Sensitive Data:** No direct PII, though `contributors` or `author` fields may contain names.
- **Timestamps:** Assumed to be in UTC, consistent with standard Odoo database configurations.
- **Data Format:** `summary`, `shortdesc`, and `description` are `JSONB` fields; ensure your query engine supports JSON path extraction (e.g., `->>`).
- **Soft Deletes:** Odoo typically does not use soft deletes for this table; records represent the current state of the module registry.
- **Precision:** `VARCHAR` fields without specified lengths are standard Odoo text fields; confirm actual data distribution if planning to materialize into fixed-width storage.
