# odoo_website_page

## Source system
This table originates from Odoo, an open-source ERP and CRM platform. The naming convention (e.g., `website_id`, `view_id`, `create_uid`) and the presence of Odoo-specific metadata fields like `is_published` and `website_indexed` are characteristic of the Odoo `website.page` model.

## Functional process 
This table supports the Content Management System (CMS) functionality within Odoo, specifically tracking the configuration and publication status of web pages. It manages the lifecycle of pages, including their URL routing, visual styling (header/footer visibility), and publication scheduling, which is essential for the "Web-to-Lead" and digital marketing lead generation pipelines.

## Description
One row in this table represents a single web page configuration within an Odoo website instance. It captures the page's routing information, visual layout settings, and publication state. As a staging table, it provides a raw, landed copy of the Odoo `website.page` model, intended for downstream transformation into a unified web analytics or content inventory dimension.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| website_id | INTEGER | true | Foreign key to the website | Links to the specific website instance. |
| view_id | INTEGER | false | Foreign key to the view | References the underlying QWeb template/view. |
| create_uid | INTEGER | true | Creator user ID | ID of the user who created the page. |
| write_uid | INTEGER | true | Last modifier user ID | ID of the user who last updated the page. |
| theme_template_id | INTEGER | true | Theme template ID | Reference to the theme-specific template. |
| url | VARCHAR | false | Page URL path | The relative URL path for the page. |
| header_color | VARCHAR | true | Header background color | CSS color value for the header. |
| header_text_color | VARCHAR | true | Header text color | CSS color value for the header text. |
| is_published | BOOLEAN | true | Publication status | Indicates if the page is live on the site. |
| website_indexed | BOOLEAN | true | SEO index flag | Determines if search engines should index the page. |
| is_new_page_template | BOOLEAN | true | Template flag | Indicates if this page serves as a template. |
| header_overlay | BOOLEAN | true | Header overlay flag | Whether the header overlays the page content. |
| header_visible | BOOLEAN | true | Header visibility | Toggle for displaying the header. |
| footer_visible | BOOLEAN | true | Footer visibility | Toggle for displaying the footer. |
| date_publish | TIMESTAMP | true | Publication date | Timestamp when the page was published. |
| create_date | TIMESTAMP | true | Creation timestamp | Record creation time in UTC. |
| write_date | TIMESTAMP | true | Last update timestamp | Record last modification time in UTC. |

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `website_id` → `website.id` (Inferred from Odoo naming conventions).
    - `view_id` → `ir_ui_view.id` (Inferred from Odoo architecture).
    - `create_uid` / `write_uid` → `res_users.id` (Standard Odoo audit fields).
- **Natural keys (inferred):** 
    - `url` (Combined with `website_id`, this typically forms the unique business key for a page).

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may need to be joined with `res_users` to identify internal staff.
- **Timestamps:** All timestamps (`create_date`, `write_date`, `date_publish`) are stored in UTC as per Odoo standard behavior.
- **Soft Deletes:** This table does not appear to use a `deleted` flag; Odoo typically performs hard deletes on these records unless a custom module is implemented.
- **Data Quality:** `url` is the primary identifier for web traffic analysis; ensure downstream models handle trailing slashes consistently.
