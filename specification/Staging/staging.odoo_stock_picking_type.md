# odoo_stock_picking_type

## Source system
This table originates from Odoo ERP, specifically the Inventory (Stock) module. The naming convention (`stock_picking_type`), the presence of Odoo-specific audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`), and the use of `JSONB` for translatable fields are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the Inventory Management and Warehouse Operations process. It defines the operational workflows for stock movements, such as "Receipts," "Internal Transfers," and "Delivery Orders." It governs how picking operations are handled, including automation settings for printing labels, reservation strategies, and default source/destination locations for specific warehouse flows.

## Description
One row represents a specific type of stock picking operation configuration within the Odoo inventory system. It acts as a template or policy definition that dictates the behavior of stock moves, such as whether to automatically create backorders or which locations to use by default. This table serves as a raw landed copy of the Odoo `stock.picking.type` model in the staging layer.

- **Soft Deletes:** The `active` column is used for soft deletes. Always filter by `WHERE active = TRUE` unless performing an audit of archived configurations.
- **JSONB:** The `name` column is a `JSONB` object (e.g., `{"en_US": "Receipts", "fr_FR": "Réceptions"}`). Ensure you extract the correct language key when querying.
- **Data Pattern:** This is a raw staging table; expect frequent schema changes if the upstream Odoo module is updated.
