# odoo_stock_putaway_rule

## Source system
This table originates from Odoo ERP, specifically the Inventory (Stock) module. The naming convention (`stock_putaway_rule`) and the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's PostgreSQL-based backend schema.

## Functional process 
This table supports the warehouse management putaway strategy process. It defines the rules that dictate where incoming products should be automatically routed (from a source location to a destination location) based on product attributes, categories, or storage categories, facilitating automated inventory replenishment and stock organization.

## Description
One row in this table represents a single putaway rule configuration that determines the destination location for incoming stock. This is a raw landed copy of the Odoo `stock.putaway.rule` model, capturing the logic used by the warehouse engine to direct stock movement. It serves as the staging entity for downstream inventory optimization and warehouse layout analysis.

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may need to be mapped to a user dimension table to avoid exposing internal system IDs.
- **Timestamps:** All `create_date` and `write_date` values are stored in UTC as per standard Odoo behavior.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = TRUE` unless historical rule analysis is required.
- **Data Integrity:** `product_id` and `category_id` are both nullable, implying a rule can be defined globally for a location or scoped specifically to a product or category.
