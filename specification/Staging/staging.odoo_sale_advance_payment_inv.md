# odoo_sale_advance_payment_inv

## Source system
This table originates from Odoo ERP, specifically the Sales module. The naming convention `odoo_sale_advance_payment_inv` and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's internal ORM-mapped tables.

## Functional process 
This table supports the "Order-to-Cash" process, specifically managing the creation of down payment invoices from sales orders. It captures the configuration parameters used when a user triggers the "Create Invoice" wizard for a down payment, determining whether to charge a fixed amount or a percentage of the total order value.

## Description
One row in this table represents a single execution or configuration state of the "Advance Payment" wizard for a specific sales transaction. It acts as a raw landing record for the parameters selected by a user during the invoicing workflow, facilitating the generation of customer invoices.
