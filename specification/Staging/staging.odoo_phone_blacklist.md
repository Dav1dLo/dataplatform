# odoo_phone_blacklist

## Source system
This table originates from Odoo ERP, as evidenced by the characteristic naming convention of `create_uid`, `write_uid`, `create_date`, and `write_date` columns, which are standard audit fields in the Odoo ORM. The table name `phone_blacklist` corresponds to the standard Odoo `phone.blacklist` model used for managing communication opt-outs.

## Functional process 
This table supports the communication compliance and marketing automation process. It tracks phone numbers that have been explicitly opted out of SMS or voice communications, ensuring that the system respects user preferences and regulatory requirements (such as TCPA or GDPR) when triggering outbound messaging workflows.

## Description
One row in this table represents a single phone number that has been blacklisted within the Odoo environment. It serves as a raw landing copy of the Odoo `phone.blacklist` table, capturing the state of communication restrictions at the time of ingestion.
