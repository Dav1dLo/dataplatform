# odoo_calendar_alarm_calendar_event_rel

## Source system
This table originates from Odoo ERP. The naming convention `_rel` combined with the specific entity names `calendar_alarm` and `calendar_event` is characteristic of Odoo's internal many-to-many relationship tables, which are automatically generated by the Odoo ORM to link calendar events with their associated notification alarms.

## Functional process 
This table supports the scheduling and notification management process within the Odoo Calendar module. It maps specific calendar events to the configured alarms (e.g., email reminders, pop-up notifications) that should trigger at defined intervals before the event start time.

## Description
One row in this table represents a single association between a calendar event and a notification alarm. It serves as a raw landing junction table, facilitating the many-to-many relationship required to allow multiple alarms to be attached to a single event, or a single alarm type to be reused across multiple events.

## Caveats for downstream consumers

- This is a junction table; queries should expect to join this against the `calendar_event` and `calendar_alarm` tables to retrieve meaningful business attributes.
- There are no timestamps or audit columns in this table; it represents the current state of the relationship as captured during the last ingestion.
- As a raw staging table, it does not contain soft-delete flags; if a record is missing from the source, it is likely removed from this table during the next full refresh.
