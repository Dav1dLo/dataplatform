# odoo_account_report_line

## Source system
This table originates from Odoo ERP, specifically the accounting module's reporting engine. The naming convention (`account_report_line`), the use of `JSONB` for localized names, and the presence of `create_uid`/`write_uid` audit columns are characteristic of the Odoo framework's internal data model.

## Functional process 
This table supports the configuration and structural definition of financial reports (e.g., Balance Sheet, Profit & Loss). It defines the hierarchical layout, grouping logic, and display properties of individual lines within these reports, enabling the Odoo reporting engine to render dynamic financial statements.

## Description
One row represents a single line item definition within a specific financial report configuration. It defines the line's position in the hierarchy, its grouping behavior, and its visual formatting properties. This is a raw landed copy of the Odoo configuration table, serving as the foundation for downstream reporting dimensions.

## Caveats for downstream consumers

- **Sensitive Data:** Contains `create_uid` and `write_uid`, which link to internal user IDs; ensure these are mapped to anonymized user dimensions if shared externally.
- **Timestamps:** Assumed to be in UTC, consistent with Odoo's standard database storage.
- **Soft Deletes:** Odoo typically uses hard deletes for configuration tables; however, verify if `write_date` shows recent activity for "inactive" lines.
- **JSONB:** The `name` column contains localized strings. Use `name->>'en_US'` or similar syntax to extract specific languages.
- **Hierarchy:** Queries traversing the tree structure via `parent_id` will require Recursive Common Table Expressions (CTEs).
