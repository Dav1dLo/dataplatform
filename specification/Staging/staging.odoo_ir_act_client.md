# odoo_ir_act_client

## Source system
This table originates from Odoo ERP, specifically the `ir_act_client` table within the Odoo framework's internal registry. The presence of Odoo-specific naming conventions like `create_uid`, `write_uid`, and `ir_act_client` confirms this is a direct extraction of the Odoo "Client Action" metadata table.

## Functional process 
This table supports the Odoo UI and navigation framework by defining client-side actions. These actions trigger specific behaviors in the Odoo web client (such as opening a specific view, executing a custom JavaScript function, or navigating to a URL) when a user interacts with menu items or buttons.

## Description
One row represents a single client-side action definition within the Odoo system. This is a raw landed copy of the Odoo metadata table, capturing the configuration, target model, and execution context for client-side events. It serves as the staging source for mapping UI interactions to system behaviors.

## Caveats for downstream consumers

- **JSONB Handling:** The `name` and `help` columns contain JSONB data; ensure your downstream transformation layer handles language-specific keys (e.g., `->> 'en_US'`).
- **Timestamps:** Odoo stores timestamps in UTC; no timezone conversion is required if the source is standard Odoo.
- **Soft Deletes:** This table does not implement soft deletes; it reflects the current state of the Odoo `ir_act_client` table.
- **Binary Data:** The `params_store` column is `BYTEA` and may contain serialized Python objects; it is generally not human-readable without Odoo-specific deserialization logic.
