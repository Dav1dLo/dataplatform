# odoo_res_device_log

## Source system
This table originates from Odoo ERP, specifically the `res.device.log` model. The naming convention (e.g., `create_uid`, `write_uid`, `create_date`) is characteristic of Odoo's base framework, which tracks audit metadata for every record in the system.

## Functional process 
This table supports the user session and device management process. It tracks authentication and activity logs for various devices used to access the Odoo instance, allowing administrators to monitor active sessions, identify the geographic origin of logins, and manage security by revoking access for specific devices.

## Description
One row in this table represents a unique device or session log entry associated with a specific user account. It serves as a raw landed copy of the Odoo device activity log, capturing technical metadata such as browser, IP address, and activity timestamps. This table is used in the staging layer to provide visibility into user access patterns and security events.

## Caveats for downstream consumers

- **Sensitive Data:** Contains `ip_address` and user-linked identifiers; ensure compliance with GDPR/privacy policies when exposing this data.
- **Timestamps:** Odoo typically stores timestamps in UTC; verify against system configuration.
- **Data Retention:** This is a log table; expect high volume and potential periodic purging or archiving of older records.
- **Nullability:** Many fields (like `country` or `city`) rely on IP-to-Geo lookup services, which may fail or return null for internal or obfuscated IP addresses.
