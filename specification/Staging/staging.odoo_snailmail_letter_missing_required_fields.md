# odoo_snailmail_letter_missing_required_fields

## Source system
This table originates from Odoo ERP, specifically the Snailmail module. The naming convention `odoo_snailmail_...` and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) and relational identifiers (`partner_id`, `letter_id`) are characteristic of Odoo's internal PostgreSQL schema.

## Functional process 
This table supports the physical mail (snailmail) dispatch process by tracking validation errors. It captures instances where a mailing attempt failed because the associated partner record lacked mandatory address fields (street, city, zip, or country) required for postal delivery.

## Description
One row represents a single validation failure event for a specific snailmail letter attempt. It acts as a raw landing copy of the error state, recording the incomplete address data and the associated partner/letter references at the time the validation failed.

## Caveats for downstream consumers

- **Timestamps:** Odoo typically stores timestamps in UTC; ensure your transformation layer accounts for this.
- **Data Quality:** This table contains "missing" data by definition; expect high nullability in address fields as these are the specific fields that triggered the validation error.
- **Soft Deletes:** Odoo does not typically use soft-delete flags; records are usually physically deleted or remain as-is.
- **PII:** This table contains address information (`street`, `city`, `zip`) and links to `partner_id`, which may be considered PII depending on your organization's data governance policy.
