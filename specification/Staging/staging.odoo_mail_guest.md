# odoo_mail_guest

## Source system
This table originates from Odoo ERP, specifically the Discuss or Mail module. The naming convention `mail_guest` and the presence of audit fields like `create_uid` and `write_uid` are characteristic of Odoo's internal ORM structure for tracking anonymous or guest users in chat channels.

## Functional process 
This table supports the guest user management process within Odoo's communication framework. It tracks external users who participate in chat sessions or support channels without having a full registered user account, storing their session preferences and identity tokens.

## Description
One row represents a single guest user session or identity within the Odoo mail system. This is a raw landing table in the Staging layer, capturing the state of guest records as they exist in the source database to facilitate downstream reporting on chat participation and user engagement.

## Caveats for downstream consumers

- **Sensitive Data:** The `access_token` is a security credential; ensure it is masked or excluded in non-privileged reporting environments.
- **Timestamps:** Timestamps are typically stored in UTC in Odoo; verify against the source system configuration if local time offsets are required.
- **Soft Deletes:** Odoo typically performs hard deletes on records; however, check for the absence of `active` boolean columns which are common in other Odoo tables to indicate soft-deletion.
- **Data Quality:** As this table tracks "guests," the `name` and `country_id` fields may be incomplete or populated based on browser-provided metadata, which can be unreliable.
