# odoo_mrp_production_backorder_line

## Source system
This table originates from Odoo ERP, specifically the Manufacturing (MRP) module. The naming convention `mrp_production_backorder_line` and the presence of `create_uid`/`write_uid` audit columns are characteristic of Odoo's internal ORM structure for tracking backorder relationships in production workflows.

## Functional process 
This table supports the manufacturing execution process, specifically handling partial production scenarios. It tracks the link between a manufacturing backorder record and the specific production orders that are being deferred or split, allowing the system to manage remaining quantities that could not be fulfilled in the initial production run.

## Description
One row in this table represents a single line item within a manufacturing backorder, linking a specific production order to a backorder header. It serves as a raw landing copy of the Odoo `mrp.production.backorder.line` model, capturing the state of production splits at the time of ingestion.
