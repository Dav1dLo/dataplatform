# odoo_project_task_recurrence

## Source system
This table originates from Odoo ERP, specifically the Project management module. The naming convention (`odoo_project_task_recurrence`) and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's PostgreSQL-based ORM structure.

## Functional process 
This table supports the recurring task generation process within the Project management module. It defines the scheduling logic for tasks that repeat at specific intervals (e.g., daily, weekly, monthly), allowing the system to automatically instantiate new task records based on the recurrence rules defined here.

## Description
One row in this table represents a single recurrence configuration rule applied to a project task. It acts as a raw landed copy of the Odoo `project.task.recurrence` model, capturing the frequency, unit, and end-date parameters for task automation.
