# odoo_hr_skill

## Source system
This table originates from Odoo ERP, specifically the Human Resources module. The naming convention (`hr_skill`), the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`), and the use of `JSONB` for localized fields are characteristic of Odoo's PostgreSQL-based backend.

## Functional process 
This table supports the Skills Management process within the HR module, allowing the organization to define a catalog of professional skills. It is used to categorize and label competencies that can subsequently be assigned to employees or job positions to track workforce capabilities.

## Description
One row represents a single skill definition within the Odoo HR system. This is a raw landing table in the Staging layer, capturing the current state of skill records as they exist in the source database. It serves as the foundational reference for mapping skill IDs to human-readable names across the data platform.
