# odoo_hr_employee_skill

## Source system
This table originates from Odoo ERP, specifically the Human Resources module. The naming convention `hr_employee_skill` and the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's PostgreSQL-based backend architecture.

## Functional process 
This table supports the employee competency management process, linking individual employees to specific skills and their corresponding proficiency levels. It is used to maintain a registry of workforce capabilities, enabling HR to track skill gaps and assign personnel based on technical or soft-skill requirements.

## Description
One row represents a single instance of an employee possessing a specific skill at a defined proficiency level. This table acts as a raw landing copy of the Odoo `hr.employee.skill` model, capturing the association between an employee, a skill, and a skill type.

## Caveats for downstream consumers

- **Timestamps:** All `create_date` and `write_date` values are stored in UTC.
- **Soft Deletes:** Odoo typically performs hard deletes on records unless an `active` flag is present; this table does not contain an `active` column, suggesting records are removed upon deletion.
- **Data Integrity:** As a staging table, this may contain orphaned records if the parent `hr_employee` or `hr_skill` records were deleted in the source system without cascading.
- **Audit Columns:** `create_uid` and `write_uid` refer to internal Odoo user IDs, which may not map to a human-readable employee name without joining against `res_users`.
