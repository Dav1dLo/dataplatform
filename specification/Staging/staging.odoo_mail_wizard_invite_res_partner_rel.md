## Source system
This table originates from Odoo ERP. The naming convention `_rel` combined with the specific module prefixes `mail_wizard_invite` and `res_partner` is characteristic of Odoo's automated many-to-many relationship tables generated by the ORM.

## Functional process 
This table supports the communication and collaboration module within Odoo, specifically tracking the association between invitation wizards (used to invite users or partners to document threads/channels) and the specific partner records being invited. It facilitates the "Invite to document" business process.

## Description
One row in this table represents a single link between a specific mail invitation wizard instance and a partner record. It serves as a raw junction table in the staging layer, capturing the many-to-many relationship required to resolve which partners are targeted by which invitation event.
