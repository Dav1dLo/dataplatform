# odoo_project_project_stage

## Source system
This table originates from Odoo ERP, specifically the Project Management module. The naming convention `odoo_project_project_stage` and the presence of Odoo-specific audit columns like `create_uid`, `write_uid`, and `JSONB` fields for translatable names are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the project management workflow by defining the lifecycle stages (e.g., "New", "In Progress", "Done") for projects. It manages the configuration of these stages, including their display order, association with automated communication templates (email/SMS), and UI behavior such as whether a stage is "folded" in the Kanban view.

## Description
One row represents a single configuration record for a project stage within the Odoo environment. This is a raw landed copy of the Odoo `project.project.stage` model, capturing the state of project lifecycle definitions at the time of ingestion.
