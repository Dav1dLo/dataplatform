# odoo_mrp_consumption_warning_line

## Source system
This table originates from Odoo ERP, specifically the Manufacturing (MRP) module. The naming convention `mrp_consumption_warning_line` and the presence of `mrp_production_id` and `product_id` are characteristic of Odoo's internal data structures for tracking manufacturing variances.

## Functional process 
This table supports the manufacturing execution and quality control process. It captures instances where the actual quantity of materials consumed during a production run deviates from the expected bill of materials (BOM) requirements, triggering a warning line for the production manager to review.

## Description
One row in this table represents a single line item within a manufacturing consumption warning, detailing the discrepancy between expected and actual material usage for a specific product. As a staging table, it serves as a raw, direct copy of the Odoo database record, intended for downstream transformation into manufacturing analytics models.

## Caveats for downstream consumers

- **Timestamps:** Values are stored in `TIMESTAMP` format; assume UTC unless Odoo instance configuration specifies otherwise.
- **Data Precision:** `DOUBLE PRECISION` is used for quantities; be aware of potential floating-point arithmetic issues when performing aggregations.
- **Soft Deletes:** Odoo typically does not use soft deletes in these tables; records are usually hard-deleted if removed from the source.
- **Audit Columns:** `create_uid` and `write_uid` refer to internal Odoo user IDs and do not contain PII, but should be joined against the `res_users` table to resolve names.
