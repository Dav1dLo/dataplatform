# odoo_website_menu

## Source system
This table originates from Odoo ERP, specifically the website module. The naming convention (e.g., `website_id`, `mega_menu_content`, `controller_page_id`) and the use of `JSONB` for localized fields are characteristic of the Odoo backend schema.

## Functional process 
This table supports the website content management process, specifically the configuration and hierarchy of navigation menus across one or more Odoo websites. It tracks the structure of menu items, their associated URLs or page references, and the visual configuration for mega menus.

## Description
One row in this table represents a single menu item within an Odoo website navigation structure. It captures the hierarchical relationship between parent and child menu items, the target URL or page, and the display properties. This is a raw landed copy of the Odoo `website.menu` model, serving as the staging point for website navigation reporting.

## Caveats for downstream consumers

- **Localization:** The `name` column is `JSONB`; ensure your downstream transformation logic extracts the correct language key (e.g., `name->>'en_US'`).
- **Timestamps:** All timestamps (`create_date`, `write_date`) are stored in UTC as per standard Odoo behavior.
- **Hierarchy:** The `parent_path` column is a materialized path; use this for efficient recursive queries rather than self-joining on `parent_id` where possible.
- **Data Integrity:** This is a raw staging table; it may contain records for multiple websites if the Odoo instance is multi-website enabled. Filter by `website_id` if necessary.
