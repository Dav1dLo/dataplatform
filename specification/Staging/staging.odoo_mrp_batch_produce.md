# odoo_mrp_batch_produce

## Source system
This table originates from Odoo ERP, specifically the Manufacturing (MRP) module. The naming convention `odoo_mrp_` and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's internal PostgreSQL schema structure.

## Functional process 
This table supports the batch production and lot tracking process within the manufacturing pipeline. It manages the configuration and metadata for generating production lots, specifically handling how components and quantities are parsed or separated during the batch production workflow.

## Description
One row in this table represents a configuration or metadata record for a specific batch production event. It serves as a raw landed copy of the Odoo `mrp.batch.produce` model, capturing the parameters used to define lot naming and quantity separation for manufacturing orders.
