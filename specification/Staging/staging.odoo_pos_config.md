# odoo_pos_config

## Source system
This table originates from Odoo ERP, specifically the Point of Sale (POS) module. The naming convention (e.g., `pos_config`, `picking_type_id`, `journal_id`) and the presence of Odoo-specific technical fields like `create_uid`, `write_date`, and `iface_*` flags are characteristic of the Odoo `pos.config` model.

## Functional process 
This table supports the Point of Sale configuration and settings management process. It defines the operational parameters for individual POS terminals, including hardware integration (printers, scales, cash drawers), accounting journals, inventory picking types, and feature toggles (e.g., restaurant mode, discount management, tax regimes).

## Description
One row in this table represents a single Point of Sale configuration instance within the Odoo environment. It acts as a raw landed copy of the Odoo `pos.config` model, capturing the state of POS settings at the time of ingestion. Its purpose in the staging layer is to provide a source for downstream reporting on POS terminal setups and operational capabilities.

## Caveats for downstream consumers

- **Timestamps:** `create_date` and `write_date` are assumed to be in UTC, consistent with standard Odoo database storage.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless historical analysis of deleted configurations is required.
- **Data Types:** Several columns (e.g., `iface_tax_included`) are typed as `VARCHAR` but likely contain categorical or boolean-like string values; verify distinct values before aggregation.
- **Sensitivity:** No direct PII is present, but `proxy_ip` and `epson_printer_ip` provide network topology information that may be considered sensitive in some security contexts.
