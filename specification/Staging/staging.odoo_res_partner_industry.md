# odoo_res_partner_industry

## Source system
This table originates from Odoo ERP, specifically the `res.partner.industry` model. The naming convention (`res_partner_industry`), the use of `create_uid`/`write_uid` audit columns, and the `JSONB` fields for multilingual support are characteristic of the Odoo framework's data structure.

## Functional process 
This table supports the Customer Relationship Management (CRM) and Partner Management processes by categorizing business partners (customers, vendors, or leads) into specific industries. It provides the reference data used to classify entities within the broader lead-to-cash and procurement pipelines.

## Description
One row in this table represents a single industry classification available for assignment to business partners. This is a raw landed copy of the Odoo configuration table, serving as a reference dimension in the staging layer. It captures both the internal identifier and the localized display names for various industry sectors.
