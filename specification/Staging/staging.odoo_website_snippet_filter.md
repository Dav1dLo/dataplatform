# odoo_website_snippet_filter

## Source system
This table originates from Odoo ERP, specifically the website builder module. The naming convention (`website_snippet_filter`) and the presence of Odoo-standard audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of Odoo's ORM-based data structure.

## Functional process 
This table supports the website content management process, specifically the configuration of dynamic content snippets. It defines how data is filtered and displayed within website blocks, linking specific server actions and filter criteria to website instances to control which records (e.g., products, blog posts) appear in dynamic snippets.

## Description
One row represents a single configuration instance for a website snippet filter, defining the parameters for how dynamic content is fetched and rendered. This is a raw landing table in the staging layer, providing a direct, un-transformed copy of the Odoo configuration records.

## Caveats for downstream consumers

- **Sensitive Data:** Contains user IDs (`create_uid`, `write_uid`) which may need to be mapped to a user dimension for PII protection.
- **Timestamps:** Assumed to be in UTC, consistent with Odoo's internal storage format.
- **Soft Deletes:** Odoo typically uses `active` flags (not present here) or hard deletes; verify if records disappear from source exports.
- **JSONB:** The `name` column is stored as `JSONB`; ensure downstream consumers have the capability to parse JSON keys (e.g., `name->>'en_US'`).
