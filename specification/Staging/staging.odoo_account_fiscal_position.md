# odoo_account_fiscal_position

## Source system
This table originates from Odoo ERP, as evidenced by the naming convention `account_fiscal_position` and the presence of Odoo-specific audit columns such as `create_uid`, `write_uid`, and `JSONB` fields for multi-language support.

## Functional process 
This table supports the tax configuration and accounting localization process. It defines fiscal positions that determine how taxes are applied based on customer location (country, zip range) or company-specific requirements, ensuring compliance with regional tax regulations during the order-to-invoice lifecycle.

## Description
One row in this table represents a single fiscal position rule used to map tax accounts or apply specific tax rates based on business logic. This is a raw landed copy of the Odoo `account.fiscal.position` model, serving as the staging entity for downstream tax and accounting reporting.

## Caveats for downstream consumers

- **JSONB fields:** The `name` and `note` columns contain JSONB data. Query writers must use the `->>` operator (e.g., `name->>'en_US'`) to extract specific language values.
- **Timestamps:** Timestamps are stored in UTC.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Ensure queries filter by `active = TRUE` unless historical analysis of inactive rules is required.
- **Data Pattern:** This is a raw staging table; expect potential schema evolution or Odoo-specific internal metadata that may not be fully normalized.
