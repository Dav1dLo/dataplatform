# odoo_res_groups

## Source system
This table originates from Odoo ERP, specifically the `res_groups` model. The naming convention (`res_` prefix, `create_uid`, `write_date`) is characteristic of the Odoo framework's base resource tables, which manage system-wide security groups and access rights.

## Functional process 
This table supports the Identity and Access Management (IAM) process within the Odoo ecosystem. It defines the security groups that aggregate permissions, which are subsequently assigned to users to control access to modules, menus, and specific data records across the business platform.

## Description
One row in this table represents a single security group definition within the Odoo system. This is a raw landing table in the Staging layer, containing the direct representation of group metadata, including localized names and administrative audit trails, as extracted from the source Odoo database.
