# odoo_pos_order

## Source system
This table originates from Odoo ERP, specifically the Point of Sale (POS) module. The naming conventions (e.g., `pos_reference`, `pricelist_id`, `session_id`) and the presence of Odoo-specific audit columns like `create_uid` and `write_uid` are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the retail sales and checkout process. It captures the header-level details of POS transactions, including financial totals, customer associations, session tracking, and payment status, which are essential for the "Point-of-Sale-to-Accounting" reconciliation pipeline.

## Description
One row in this table represents a single Point of Sale order header. It acts as a raw landed copy of the Odoo `pos.order` model, capturing the state of an order at the time of ingestion. Its purpose in the staging layer is to provide a granular, immutable record of POS transactions for downstream transformation into sales facts.

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `partner_id` → `res_partner.id` (Standard Odoo partner link)
    - `session_id` → `pos_session.id` (Links to the POS session container)
    - `user_id` → `res_users.id` (Links to the system user)
- **Natural keys (inferred):** 
    - `name` (The human-readable POS order reference)
    - `uuid` (The system-generated unique identifier for sync)

## Caveats for downstream consumers

- **PII:** Contains `email` and `mobile` fields; ensure these are masked or handled according to data privacy policies.
- **Timestamps:** All timestamps (`date_order`, `create_date`, `write_date`) are assumed to be in UTC, consistent with standard Odoo backend behavior.
- **Soft Deletes:** Odoo typically does not use soft deletes in this table; records are usually permanent once created.
- **Precision:** `NUMERIC` fields do not specify scale/precision in the metadata; assume standard Odoo accounting precision (usually 2 or 4 decimal places). Verify against source if performing high-precision financial aggregation.
