# odoo_stock_rule

## Source system
This table originates from Odoo ERP, specifically the Inventory/Warehouse management module. The naming convention (e.g., `stock_rule`, `picking_type_id`, `procure_method`) and the use of Odoo-specific patterns like `create_uid`, `write_uid`, and `JSONB` for translatable fields are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the inventory replenishment and supply chain execution process. It defines the automated rules that dictate how products move between locations (e.g., push/pull rules, procurement methods, and transit delays) within the warehouse network, effectively governing the "Lead-to-Stock" or "Stock-to-Customer" fulfillment logic.

## Description
One row represents a single inventory rule that determines how stock moves between a source and destination location when triggered by a procurement or replenishment event. This table serves as a raw landed copy of the Odoo `stock.rule` model, capturing the configuration logic for automated warehouse operations.
