# odoo_res_currency

## Source system
This table originates from Odoo ERP, specifically the `res_currency` model. The naming convention (`res_` prefix) and the presence of Odoo-specific audit columns like `create_uid`, `write_uid`, and `JSONB` fields for multi-language labels are characteristic of the Odoo framework's core configuration tables.

## Functional process 
This table supports the multi-currency management process within the ERP. It serves as the master registry for all currencies supported by the system, defining how monetary values are formatted, rounded, and identified across financial modules, including accounting, invoicing, and purchasing.

## Description
One row in this table represents a single currency definition available for use within the Odoo platform. It acts as a raw landed copy of the system's currency configuration, providing the metadata necessary for currency conversion, display formatting, and rounding logic.

## Caveats for downstream consumers

- **Timestamps:** `create_date` and `write_date` are stored in the Odoo server's timezone (typically UTC); verify against system configuration.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless historical audit is required.
- **JSONB Fields:** `currency_unit_label` and `currency_subunit_label` contain JSON objects; use PostgreSQL `->>` operator to extract specific language values (e.g., `currency_unit_label->>'en_US'`).
- **Data Sensitivity:** No PII or sensitive financial data is contained in this table; it is a configuration/master data table.
