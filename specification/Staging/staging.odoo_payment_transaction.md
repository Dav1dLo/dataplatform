# odoo_payment_transaction

## Source system
This table originates from Odoo ERP, specifically the `payment.transaction` model. The naming conventions (e.g., `create_uid`, `write_uid`, `partner_id`) and the specific structure of the payment processing module are characteristic of Odoo's backend database schema.

## Functional process 
This table supports the payment processing and reconciliation pipeline within Odoo. It tracks the lifecycle of financial transactions initiated through various payment providers, linking them to specific partners, currencies, and underlying business documents like Point of Sale orders or general payment records.

## Description
One row represents a single payment transaction attempt or completion within the Odoo system. It captures the state of the transaction, the associated financial amount, and the customer's contact details at the time of the transaction. This is a raw landing table representing a point-in-time snapshot of the `payment.transaction` model in the source Odoo database.

## Caveats for downstream consumers

- **PII:** This table contains sensitive customer information (`partner_email`, `partner_phone`, `partner_address`). Ensure appropriate masking for non-authorized users.
- **Timestamps:** All `TIMESTAMP` fields are assumed to be in UTC, consistent with standard Odoo server configurations.
- **Soft Deletes:** Odoo typically does not use soft deletes in this table; records are usually permanent once created.
- **Denormalization:** Several columns (e.g., `partner_name`, `partner_email`) are denormalized snapshots. They may differ from the current values in the `res_partner` table if the partner's details have changed since the transaction occurred.
