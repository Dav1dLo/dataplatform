# odoo_account_analytic_line

## Source system
This table originates from Odoo ERP, specifically the analytic accounting module. The naming convention (`account_analytic_line`), the presence of Odoo-specific audit fields (`create_uid`, `write_uid`), and the reference to `move_line_id` and `so_line` (Sales Order line) are characteristic of Odoo's internal database schema.

## Functional process 
This table supports the analytic accounting and project costing process. It tracks financial and non-financial movements (such as hours worked or costs incurred) against analytic accounts, allowing businesses to perform cost center analysis, project profitability tracking, and budget monitoring independent of the general ledger.

## Description
One row in this table represents a single analytic entry, which records a specific financial amount or quantity associated with an analytic account. This is a raw landing table in the staging layer, capturing the state of analytic lines as they exist in the Odoo database at the time of extraction.
