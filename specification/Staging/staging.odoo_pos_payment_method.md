# odoo_pos_payment_method

## Source system
This table originates from Odoo ERP, specifically the Point of Sale (POS) module. The naming convention (`odoo_pos_payment_method`) and the presence of Odoo-specific audit columns like `create_uid`, `write_uid`, and `journal_id` are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the Point of Sale configuration and transaction processing pipeline. It defines the available payment methods (e.g., cash, bank, terminal) for POS sessions, linking them to specific accounting journals and receivable accounts to ensure financial reconciliation during the end-of-day closing process.

## Description
One row in this table represents a single payment method configured for use within the Odoo Point of Sale system. It acts as a raw landed copy of the Odoo `pos.payment.method` model, capturing configuration details such as terminal integration, accounting mappings, and display names. This table serves as a reference entity within the staging layer to facilitate the mapping of POS transactions to their respective payment types.

## Caveats for downstream consumers

- **PII/Sensitive Data:** The table contains audit user IDs (`create_uid`, `write_uid`) which may need to be joined with user tables to identify specific employees.
- **Timestamps:** All `create_date` and `write_date` values are stored in UTC.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = TRUE` unless historical configuration analysis is required.
- **JSONB:** The `name` column is a `JSONB` object; downstream consumers will need to extract the relevant language key (e.g., `name->>'en_US'`) to display the name.
