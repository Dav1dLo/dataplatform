# odoo_fetchmail_server

## Source system
This table originates from Odoo ERP, specifically the `fetchmail_server` model within the Odoo framework. The presence of columns like `create_uid`, `write_uid`, and the specific naming convention for Odoo's email server configuration (e.g., `server_type`, `is_ssl`, `google_gmail_*`) confirms this is a direct extraction of the Odoo email gateway configuration settings.

## Functional process 
This table supports the "Inbound Email Integration" process, which allows Odoo to poll external mail servers (POP/IMAP) to automatically create records such as leads, support tickets, or tasks from incoming emails. It manages the connection parameters, authentication credentials (including OAuth2 tokens for Gmail), and processing rules for these mail servers.

## Description
One row in this table represents a single configured incoming mail server connection within the Odoo instance. It acts as a raw landed copy of the Odoo `fetchmail.server` model, capturing the technical configuration, authentication details, and status flags required for the system to fetch emails.

## Caveats for downstream consumers

- **Sensitive Data:** This table contains highly sensitive credentials, including `password`, `google_gmail_access_token`, and `google_gmail_refresh_token`. These columns must be masked or excluded in non-production environments.
- **Timestamps:** All timestamps (`date`, `create_date`, `write_date`) are stored in UTC as per Odoo standard practice.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = TRUE` unless auditing historical configurations.
- **Data Pattern:** As a raw staging table, this may contain legacy or deprecated columns depending on the specific Odoo version (e.g., `script` is rarely used in modern Odoo versions).
