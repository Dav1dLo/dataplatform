# odoo_product_attribute_value

## Source system
This table originates from Odoo ERP, an open-source business management software. The naming convention (e.g., `create_uid`, `write_uid`, `write_date`, `JSONB` for translatable fields) is characteristic of the Odoo ORM's standard database schema.

## Functional process 
This table supports the product configuration and e-commerce catalog management process. It defines the specific values available for product attributes (e.g., if the attribute is "Size", the values might be "Small", "Medium", "Large"), which are then used to create product variants in the product catalog.

## Description
One row represents a single selectable value for a specific product attribute within the Odoo system. This is a raw, landed staging table containing the full attribute value definition, including display properties like color and pricing modifiers. It serves as the primary source for mapping product variants to their respective attributes.

- **Timestamps:** Assumed to be in UTC, consistent with standard Odoo deployments.
