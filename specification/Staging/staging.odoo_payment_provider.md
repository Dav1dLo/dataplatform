# odoo_payment_provider

## Source system
This table originates from Odoo ERP, specifically the payment processing module. The naming convention (e.g., `company_id`, `create_uid`, `write_date`, `JSONB` fields for localized messages) is characteristic of the Odoo ORM structure.

## Functional process 
This table supports the configuration and management of payment gateways (e.g., Stripe, PayPal, Wire Transfer) within the Odoo ecosystem. It defines how payment forms are rendered, whether tokenization is enabled, and the specific messaging displayed to users during various stages of the payment lifecycle.

## Description
One row represents a single configured payment provider instance within the Odoo environment. It acts as a raw landed copy of the `payment.provider` model, capturing the configuration settings, UI view references, and localized status messages for each provider.

    - `website_id` → `website.id` (Standard Odoo multi-website architecture).

    - `code` (The internal provider identifier is unique within an Odoo instance).

## Caveats for downstream consumers

- **Sensitive Data:** The `JSONB` fields may contain HTML or text that could be considered PII depending on the content; ensure appropriate handling.
- **Timestamps:** All `create_date` and `write_date` values are stored in UTC.
- **Soft Deletes:** Odoo typically uses `active` flags (not present here) or hard deletes; assume this table contains current active configurations unless otherwise specified by the source system's behavior.
- **JSONB:** The `name` and `*_msg` columns contain JSON objects. Use `->> 'en_US'` or similar operators to extract specific language values in PostgreSQL.
