# odoo_calendar_alarm

## Source system
This table originates from Odoo ERP, specifically the calendar module. The naming convention `odoo_calendar_alarm` and the presence of Odoo-specific audit columns like `create_uid`, `write_uid`, and `JSONB` fields for multi-language names are characteristic of the Odoo PostgreSQL schema.

## Functional process 
This table supports the calendar notification and reminder system. It defines the configuration for event alarms, including the timing (duration/interval), the notification method (alarm_type), and associated templates for email or SMS communications used in scheduling and event management workflows.

## Description
One row represents a single alarm configuration used to trigger notifications for calendar events. This is a raw landed copy of the Odoo `calendar.alarm` model, serving as the staging entity for downstream event-reminder reporting and notification analytics.
